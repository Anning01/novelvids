# 生成本集分镜

以 chapter 作为本集拍摄正文：有导演剧本就按剧本拍，没有剧本时才按本章原文改编。保留关键动作、对白原意、说话者和揭示顺序。story_memory 只用于接戏：用年代、当前世界、人物身份与前情校准画面。只有正文明确要拍回忆、穿越或前情时才呈现相应事件。沿用项目视听约定、画风与叙事策略。

一个 shot 对应一次视频生成。按导演场号分别估时；没有场号时按实际时空和连续表演组织。同一场号内先把一轮完整表演连起来：例如敲门、开门、交信、接信人的反应，在 shot_duration_range 内能自然演完就写成一个 shot。用 actions 安排节拍，移焦或推近写入运镜，确需段内硬切才用 segments，各段时长之和等于本镜总时长。换人说话、人物反应、道具特写或屏显可以发生在同一次生成内。

同场连续表演超过单镜上限时，在完整话意或动作落点处分段，后镜承接前镜的站位、朝向、道具与声音。保留实质时空跳转和导演明确要求独立生成的段落。出稿前检查相邻同场短段：合起来仍能在时长内自然演完的，合成一段；保留必要的停顿和台词，不为减少段数加快语速。

duration 是数值秒数，遵守输入的 shot_duration_range。actions、dialogue、narration 的 start、end 是本镜内的数值秒数。对白和旁白填写 speaker、delivery、text，保留原话正文；没有时返回空数组。旁白、内心 OS 与对白的时间窗不重叠。内心 OS 在 delivery 标明，现场画外声与旁白保持区分。

所有资产引用只能从本次 entities 候选中选择，名称字段遵循平台 Schema 的 enum，不新增或猜测候选以外的资产及形态。visible_asset_names 列出本镜引用的全部角色、场景和道具，使用已登记的精确资产名或“基础名#形态名”。发声角色也属于角色引用，统一列入名单；是否出现在画面中由镜头描述决定。画面描述可以使用 @{完整实体名}；对白正文不把称呼替换成素材标记。电影叙事遵循提供的策略限制，旁白叙事使用已确认的旁白。

镜头编号、时间标记、固定栏目与最终提示词由平台生成。开启空间定位图时，随本次结果给出每镜的 blocking_map，复用同场景的布局方向与几何锚点，描述人物、道具及机位。按相邻镜头的终态接续，不再安排额外补图或审查任务。

本集时长与节奏是创作参考，允许为完整表达适度超出；每镜仍遵守视频模型的时长范围。只完成当前本集分镜，不自动生成图片或视频。
