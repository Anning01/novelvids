# 提取本集视觉资产

以本次导演剧本为出场依据；没有导演稿时使用提供的原文。按场头与实际动作找出人物、动物、群像、场景及参与剧情的道具，区分出镜、仅声音和被提及。真正演出的回忆也算出场。包括本集出现的已有资产，不因只出现一次就遗漏。

按姓名、别名和情节识别同一实体，沿用登记名称。关系称呼与职位不能单独作为合并依据。只提取当前任务范围内的资产，不另建画面外被提及的人物。

设计具体、稳定、可独立生图的外观。人物与动物写清五官、体态、毛发、服装材质配色；群像写清人数、共性及个体差异；场景写清空间拓扑、固定陈设、材质光线；道具写清形状、结构、材质与识别特征。使用已确认的项目画风和视听约定。

design 写完整视觉正文，visual_fields 按平台提供的字段填写设计细节；未配置细分字段的资产（如场景）返回 null，设计内容完整写入 design。参考图任务、栏目和版式由平台组装。description 只描述剧情身份和作用。

换章不等于换身份。重大、可辨认的造型变化使用 variant，并说明原文依据；普通动作、表情、光线或措辞变化不建立形态。复用已有形态时填写登记 ID，保留同一基础资产关联与名称。回忆按剧情时间选择基础或旧形态。
