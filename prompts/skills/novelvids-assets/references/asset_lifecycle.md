# 占位、正式设计与衍生形态

本规则适用于人物（含动物与群像）、场景和道具；所有名称、说明、变化依据和视觉提示词遵循任务 language，所有新设计遵循当前资产输出协议。

资产提取：
- requires_design_completion=true 的资产是“当前章节”列表中已关联的剧本占位资产，属于本次必需补全范围；即使仅在对白中提及、未实际出场，也必须按目录标准名返回完整正式设定，不能因为出场筛选而遗漏。这是补全已登记资料，不是新增出场人物；不得因此添加剧情、台词或镜头。其他未登记且只被提及的对象仍不新建。
- metadata.analysis_source=project_analysis 是剧本分析占位，不是已确认的美术设计。首次正式提取必须结合本章重新完成 base_traits，并覆盖该占位；即使 mode=fill_missing 也必须完成。保留身份、别名、图片和声音绑定。
- 已正式提取的基础形象默认沿用。后续章节没有重大外形变化时，base_traits 保留原设计，variant=null；措辞、镜头角度、表情、动作、光照、临时伤势不构成新形态，也不以文本差异作为变化依据。
- 只有原文明确支持成长/年龄阶段变化、转入其他宗门导致服装体系改变、场景重建/毁坏、道具重铸/变形等影响稳定外形的变化时，才填写 variant={name,description,base_traits,change_reason}。change_reason 写本章的具体依据；base_traits 是完整新形态提示词，不能只写与原形象的差异。基础 base_traits 仍保留原设计，不能把新形态覆盖到基础资产。
- 对照目录 variants 的名称、外形、剧情阶段与 chapter_numbers 判断是否已有相同形态；相同则精确复用其 name、description 和 base_traits，记录本章适用关系，不因章节不同或措辞不同重复创建。人物长大但衣服未变也须根据稳定体貌判断；只有身份/职位变化而外形未变时不衍生。
- 所有本章出场的已有资产仍须返回，以同步别名与出场章节。新资产或占位资产以本章主要形象完成基础设计。不得把形态名称作为新人物、新场景或新道具的标准名。

分镜提取：
- entities 中 @{标准名} 表示基础形象，@{标准名#形态名} 表示该资产的衍生形态；它们是同一身份的不同外观，不是不同人物/场景/道具。已明确选定形态的实体以提供的名称和描述为准。
- 比较每个镜头的剧情时间、年龄、服饰、地点状态或道具状态，自主选择准确形态。chapter_numbers 是已确认使用记录，不是强制全章套用：回忆、闪回应选当时的形象，当前剧情选当前形象。
- 每个镜头中同一资产只引用一种形态；视觉描述、动作主体和说话者一致使用所选精确标记，不能又混用基础名标记。同一章可在不同镜头选择基础与衍生；同一镜头需要不同阶段时拆成独立镜头。
- 不能编造目录里不存在的形态。没有重大变化时继续使用已有形象，不把形态变化当作新人物首次登场重新介绍。
