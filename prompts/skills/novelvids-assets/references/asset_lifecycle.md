# 占位、正式设计与衍生形态

本规则适用于人物（含动物与群像）、场景和道具；所有名称、说明、变化依据和视觉提示词遵循任务 language，所有新设计遵循当前资产输出协议。

资产提取：

1. 每个基础资产用同一标准名或既有 ID。按场号记录实际使用的形态；同场拔剑变形、当场卸去易容时，分别记变化前后和触发动作。衣装、妆面、易容、武器变化、建筑改建或毁坏，只要需要不同视觉设计，就挂在原资产下。已有形态优先复用；回到旧装或闪回时，按当时的形态取用。仅切换画法时沿用同一形态，单独记录该场的风格。动作、表情、光照和物件数量按场接戏。
2. 当前场次写“仍着那身衣服”或没有交代剑、建筑的当前外形时，直接回读本项目可读的前后章。先向前找最近一次可核实的变化，再向后找身份线索或变化发生点；必要时对照相应原文章节的外观描述。记录依据到场号或段落。后文才重铸的剑，生效点从重铸那场起。相邻章节尚未提供时，向用户索取对应场段；仍有歧义就标为待确认。
3. 每个形态交付完整视觉提示词和 change_reason（变化发生在哪一场、根据哪个动作）；基础设计保留原样。基础形象沿用时 variant=null。目录中与本章关联、标记 requires_design_completion=true 的占位条目另行补全，沿用原身份和声音绑定。出场统计仍按导演剧本。
4. 项目记忆在下次提取前要能读回。先读取项目资产目录和连续性记录，处理完将新增或修正的记录按资产与场号合并。宿主有项目记忆时写入项目；本地有项目目录时维护该项目的「资产连续性.md」。纯对话或只读环境交付同样的交接记录，供下次随项目传入。以实际读回的记录为依据。已确认和待确认分开记；同一场重跑更新原记录。

连续性记录写清两件事：哪些世界或场段已确认用哪套画法；每个「资产标准名／形态名」在哪些场段生效，以及设计依据、沿用的参考图部位。示例：青岚剑／断刃，2-3 挡门后至 3-1 重铸前，依据为 2-3 的断剑动作。后来恢复完好，保留旧场的断刃记录。

分镜提取：
- entities 中 @{标准名} 表示基础形象，@{标准名#形态名} 表示该资产的衍生形态；它们是同一身份的不同外观，不是不同人物/场景/道具。已明确选定形态的实体以提供的名称和描述为准。
- 比较每个镜头的剧情时间、年龄、服饰、地点状态或道具状态，自主选择准确形态。chapter_numbers 是已确认使用记录，不是强制全章套用：回忆、闪回应选当时的形象，当前剧情选当前形象。
- 每个镜头中同一资产只引用一种形态；视觉描述、动作主体和说话者一致使用所选精确标记，不能又混用基础名标记。同一章可在不同镜头选择基础与衍生；同一镜头需要不同阶段时拆成独立镜头。
- 不能编造目录里不存在的形态。没有重大变化时继续使用已有形象，不把形态变化当作新人物首次登场重新介绍。
