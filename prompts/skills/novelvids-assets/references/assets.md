# 资产设定

## 逐场定名单

小说改编项目以本次导演剧本为出场依据。只有小说时先请用户提供改编稿。按场号核对场头和 △ 动作，找出谁行动、谁被照料、什么动物载人、地点在哪里、哪件实物参与了动作。读完全场再区分出镜、仅声音和被提及；真正演出的回忆也算出场，已去世不等于没有出场。汇总时包含已登记且本章出场的资产，不能只返回新对象或变更项。只出场一次但决定剧情的主体同样入册。

名单定好后，按资产名、别名和对应情节查小说原文，补五官、体态、衣料、器物结构、建筑陈设等视觉细节。改编稿写“竹哨”，原著写“玉笛”，这一场提取竹哨；若原著另外写到掌柜，剧本没让他出镜，就不建掌柜。原文里的外观只取与本场身份和形态相容的部分。

## 风格确认与参考图

清点时标出每场所在世界、时代和生效的造型。先读用户已确认的风格及适用范围；第一次设计或切到尚未确认的新世界时，按范围一次问清，例如：“现代城市场用 3D都市动画，古代山村用 3D写实国风，还是两边都用你指定的画法？”允许选内置风格或给自定义描述。等用户回答再写该范围的成图提示词；已有明确选择的场次直接沿用。跨界当场按穿越前后分别记，穿回已确认的世界沿用其约定。同一人物可保持脸和身材，换用该场的画法及剧本指定的当场装束。

对每张参考图，按用户指定的对象和部位取用：身份参考看脸型、五官和体态；服装、妆造、道具、布局或画风可另指图。参考白衣人物设计放牛娃时，取脸和身形，衣着按剧本写粗布短褂，原文可补衣料的磨损。把采用的具体部位写进该形态提示词。多图可分别供脸、妆和衣服；同一部位指向冲突时，只问用户以哪张为准。

## 视觉设计

先区分实体，再合并同一实体的本名、昵称与别名，保留已登记标准名。关系称呼、职位或头衔可能多人共用，不能单凭“师父”“宗主”“父亲”等称呼相同就合并；根据说话人、被指代对象、姓名、年龄与经历核对身份，不把师徒、前后任或同名者的资料互换。已登记人物不能因另一人物更需要补充而漏报。
人物、场景、道具分开管理。章节变化使用形态，保留角色声音绑定；不要把局部换装改成全项目身份变化。
视觉设定的目标是让画师仅凭这一份提示词就能重建同一资产，不是摘抄人物简介或压缩剧情摘要。严格遵循随请求提供的资产输出协议，禁止用自由散文替代固定字段。每份 base_traits 必须依次包含：完整 task 任务模板（将 aspect_ratio 替换为项目实际比例，其余任务模板逐字保留）、本场确认的完整视觉风格、对应 heading 描述标题、具体视觉描述。任务模板必须在最前面，不要把构图规则缩成末尾一句“版式”。
单人及动物使用 person 协议，描述标题下严格按 fields 顺序输出14行；群像使用 group 协议，严格输出15行。每行格式为 **字段名**: 具体设计内容，不得合并、省略、重排或添加字段；字段名与内容使用任务语言，字段顺序与名称以本次协议为准。场景使用 scene 协议，完整保留四宫格任务、逐条限制、比例要求，再写风格和“场景描述”下的连续空间说明。道具使用 item 协议，其 task 为空：必须直接以“【道具描述】”（英文对应标题）开头，标题后写完整造型与风格，在末尾原样保留 suffix 禁止项，不擅自改成新人物任务或增加展示板模板。场景和道具不套用人物字段。风格和版式不能代替主体设计，也不能为了批量返回而把每项压成一句话。

单人和动物：交代时代基底、国家/朝代或地域文化、人种（动物为物种/品种）、世界观类型、性别与年龄范围。详细设计脸部轮廓、眉眼形态与眼睛颜色、鼻梁鼻头、嘴唇、肤色肤质和稳定面部特征；发型、发色、长度、发质和整理方式；耳饰或明确不佩戴的设计；身高或体长、骨架、胖瘦、肌肉、四肢比例、稳定体态和头身比。分别写清上装、下装、鞋履及固定配饰的颜色、材质、剪裁结构、层次、纹样与磨损。动物对应描述头脸与口鼻耳部、毛羽鳞片的分布纹理、躯干四肢与爪蹄、固定装具，不能硬套人类服饰。
“长相普通、短发、普通校服”只算身份概述，不能作为完整设计；即使原文如此简写，也要在不改变人物身份的前提下，将五官、头发与校服的具体造型、配色、材质、上下装和鞋履落实为可复现的设计。同龄同职业人物要结合各自体格、性格和经历作克制的视觉区分，不能只替换姓名或临时表情。

群像：交代群体身份、时代文化、年龄段、性别与族裔/物种构成、人数规模；写清共同气质与体型范围、脸型、眉眼、鼻唇、肤色肤质、发型发色、眼镜或其他配饰、稳定识别标记、服装体系与共有道具。每个维度先写共性，再给出有依据的个体差异范围，避免所有人复制同一张脸；有明确成员时分别说明其身份、位置关系与辨识点，不把主角无依据塞入群体。群像使用多人关系参考图，不为每个成员堆叠单人三视图，也不将冲锋、饮酒等当前动作固化为默认形象。

场景资产与场景形态一律做空场景底图。出场名单、人物和动物的位置属于分镜接戏资料；生图提示词只写环境。用固定物交代距离，例如“牛槽南侧留一米空地，槽西端距草堆半米”。改稿时也逐句移走角色站位、动作、剪影及倒影，把有用的空间关系改写为固定物之间的方位。

场景：说明时代与地域建筑风格、室内/室外、整体规模、空间外形、主轴与延伸方向。按近景、中景、远景描述地面、建筑、地形和固定陈设；关键元素必须有前后左右、相对比例与连接关系，成组或重复元素交代有依据的数量、排列、间距和覆盖范围，保持空间拓扑可重建。写清材质、配色、表面质感、稳定光源方向、天气与基础氛围。原文未定的普通环境细节可结合语境作内部一致的设计，不臆造影响剧情的建筑或机关。不要只写“普通教室、几张桌椅”；不能用“旁边、附近”代替关键空间关系。主体设计与 image 的四格透视版式一起写全，不恢复旧式正交投影或建筑平面图规则。

道具：说明品类、用途、整体轮廓、尺寸级别和长宽厚比例；具体描述材质、配色、结构部件及连接方式、纹样、表面质感、磨损与稳定识别特征。结合语境补齐普通设计细节，不写“木或金属”等互斥备选，不编造影响剧情的功能、品牌、铭文或关键结构。不同角度、开合和临时使用状态不新建身份。参考图突出完整物体及关键结构，背景简洁，不加入持有人、使用动作或无关陈设。

以剧本当场造型和适用的已确认设定为准，原文补足相容细节。未明确的外观应结合时代地域、世界观、身份职业、性别年龄、性格经历作克制且一致的美术设计；不使用“未知、未提及、无法确认”等占位值，不编造剧情关键伤疤或关键道具。没有耳饰、眼镜等应明确为不佩戴的设计结论。不写“可戴、或、任选”等互斥备选设计；不要凭空添加手表等原文未提及且非必要的配饰。胸部以上特写不要求展示手腕或鞋履等取景范围外的细节。只写稳定体貌与装束，不把当前哭泣、跪拜、坐化、伤势变化等临时状态当成常规形象。
description 用于剧情定位，base_traits/prompt 保存完整生图提示词。按 image 规则完成版式，从 styles 取该范围已选画法，或落实用户的自定义描述。
所有写入先校验归属和引用。用户只要求提取或设定时不自动生图。

输出前逐项自检：每份 base_traits 都包含完整任务模板、本场风格、描述标题和对应的固定字段或环境/道具描述，且遵循任务 language 与项目比例。description 仅负责剧情定位，不能用它代替 base_traits 中缺失的视觉细节；不要把整批的公共规则只写在某一个资产里。已有确认设计的具体内容保留；本次重新提取时将自由散文、简略提示词和缺失模板的旧内容整理到当前协议，不因旧格式错误而改动已确认的形象。

先定位要改的基础资产或具体形态，读取其完整设定。比如只改第三章的外套，就在该章形态中更新服装，保留基础身份、脸部特征、声音绑定和其他章节的造型。按原类型协议交付完整修订稿，沿用字段顺序、本场确认的风格与已确认设计。
