# 图片制作

读取目标资产、形态、已有提示词、项目比例与风格、参考图和所选模型能力。
已有完整提示词必须原文提交。为空或明确要求编写时，输出一个完整、可独立执行的提示词并保存版本。

同项目的单人、群像、形态、场景与道具共用项目选定的视觉风格。读取 styles 中对应 key 的完整渲染要求（自定义风格优先），将人物比例、五官造型、皮肤着色、材质与光影要求一致地写入每份完整提示词，不能只写风格名称或“PBR”。年龄、皱纹、情绪与人数只改变内容，不改变项目的渲染风格；不能因版式不同自行切换真人摄影、国风 CG 或夸张卡通。风格定义画法；时代、服装、发型与建筑仍遵循故事和已确认设定。
有参考图时，在完整提示词中写清每张图用于人物身份、画风或空间布局；风格参考不复制其中的人脸。复用同一角色需保留其已确认形象；多人同框需要明确成员及各自的参考图，独立“同事”群像不自动包含项目中所有主角。仅有文字或风格 key 时不能声称已锁定人脸一致性。

角色默认使用同一人物上半身正面平视特写与全身正、侧、背三视图：左侧约40%，右侧约60%，浅灰白无缝背景、轻接触阴影、无分割线、无文字水印。群像描述群体身份与个体关系，不套用单人三视图。
场景参考图是一张用于视频制作的四格电影场景图：2×2等大画面，左上正面、右上高位俯瞰、左下反向、右下侧向，均使用有纵深的透视镜头。同一空间的四个机位保持建筑、固定陈设、布局、比例、材质、天气和光源位置一致，不出现人物或临时道具。每格环境画面铺满到边缘，四格紧贴，只用细分隔线区分；不要留白、外框、圆角相框或标题栏，不画文字、视角名称、编号、图例、Logo和水印；不要建筑制图、正交投影、平面图或带注释的设计展示板。必须把这些版式要求写进保存的完整提示词，不能只写“四视图”让模型自行决定排版。室内与室外场景均遵循该规则；用户明确指定其他版式时以其要求为准。
道具写明轮廓、比例、材质、颜色、结构、纹样、磨损和识别特征，不虚构品牌和文字。
项目封面使用竖版2:3电影主视觉，突出主要冲突与氛围，无标题、文字、Logo、水印和边框。
将所选风格与版式写进完整提示词，不依赖生成工具再次补充。模型限制以能力接口为准。
提交后记录真实任务ID，等待后台结果。没有生成请求时，仅保存设计。
