# 视频制作

高清导出采用“先低清制作与定稿，再增强已确认的视频”。prepare_export 准备完整采用镜头的不可变原片；enhance_export 只处理用户确认的具体导出版本、目标清晰度与服务端报价，按服务已启用且已配置价格的档位选择720p、1080p、2k或4k，并保持原帧率，不重写提示词、不重生成视频、不主动插帧。查询和下载恢复不持续调用文本模型；原片与高清版分别保留，供应商任务成功不代表文件已保存。缺少配置、来源或明确付费授权时先提示完成对应步骤。

读取已保存完整镜头提示词、模型能力、分辨率、比例、时长、参考图/视频/音频和角色绑定。
默认原文提交；仅在缺失或明确优化要求时修改提示词。生成接口处理媒体排序、声音映射、URL与供应商参数，不由模型猜测。
仅执行本轮明确要求的镜头和数量；批量部分失败保留成功结果。不要自动发起付费改进轮次。
首尾帧、参考模式等限制以配置能力为准。开启连续生成时先等上一个视频完成，再把真实尾帧交给下一镜头；跨章沿用现有角色身份及声音。
全能参考模式的衔接图作为参考图片上传，并在提示词中明确它是本镜头的起始画面；图片编号必须对应最终去重后的媒体顺序，不能把素材文件名或 first_frame_reference JSON 当作供应商首帧参数。全能参考与严格首尾帧模式互斥，不能混传 reference_image 与 first_frame/last_frame；参考衔接不承诺首帧逐像素一致。严格锁帧应使用模型支持的首帧或首尾帧模式及对应角色参数。
提交成功只报告已提交，后台完成后报告真实文件与状态。网络结果不明确时待核对，不能自动再次收费提交。
合成沿章节顺序使用当前生成版本，缺失镜头按用户 strict 选择报错或使用已完成视频。不要删除原媒体。

分镜和工作流可以单独高清化已生成成功的视频，不要求整章完成。画布通过视频输出连线直接创建新的视频卡片，在卡片内选择目标清晰度、确认费用并查看结果，无须中间转换器。服务端冻结具体视频版本，复用相同来源、服务与目标清晰度的任务与结果；只允许实际分辨率提升，1080p不能再转1080p，可在服务允许的输入范围内升至更高档位；2K、4K输入仍需满足服务能力，不能为了绕过限制悄悄换回原片。单条视频高清化成功后自动设为当前分镜视频，预览、下载与合成沿用高清版，原视频仍保留在历史记录中；增强期间若已手动换片或选了更高分辨率结果，不覆盖用户的新选择。已完成的历史高清结果可免费设为当前版本，不重新提交增强。整集导出保持独立版本，不把整集结果绑定到某个分镜。
