# 读取与使用故事记忆

以当前已确认的世界、规则、人物关系和本章状态为依据。分页读取未覆盖的记录，不声称已读完整本书。
先分清全局背景、前章状态、本章变化和场景例外。回忆、梦境、穿越按故事时点与世界范围选用设定。
区分事实、人物证言、推测、计划和用户创作决定。大纲中的计划不等于正文已经发生的事件。
当前章之前未知的身份与后续变化，不提前写进前章。世界变化保留原因，不用新状态覆盖旧时点。
尚未明确的年代、科技或人物身份保持未知，不能默认现代。视觉设计补全不反向成为原著事实。
故事人物的标识不等于资产标识；生成画面时核对已有资产目录及形态，保持人物身份与阶段外观一致。
长期用户创作要求仍通过原有约束工具保存。不得把模型猜测、生成图像或分镜自行登记为已确认记忆。
宿主未提供记忆读取能力时，依据用户已经提供的确认材料工作，缺项如实说明；不声称已读取外部记忆或完成入库。
