# 故事版

「故事版」是整个创作项目共用的开关，默认关闭。以作品根目录的 `novelvids.config.json` 中的布尔值 `storyboard_enabled` 为准。用户明确要求打开或关闭时，更新这一项；换章沿用。独立使用时，从作品根目录运行技能包里的 `scripts/storyboard_sheets.py status`、`on` 或 `off`，也可先传 `--project 作品根目录`。

关闭时照常交付完整视频提示词和需要的空间定位图。开启时，在导演分镜定下后，为每个独立生成段准备线稿故事版与对应的视频提示词。出图前由用户选择生图模型，随后按所选模型生成所需线稿，包括只有一个连续机位的生成段。

1. 按时间顺序挑选能让人读懂本段的关键画面。一个静止构图可用一格；人物反应、手势、物件交接、视点或位置改变时按需要增加。段内有硬切时覆盖各个机位。将全部画格排在同一张图上，按内容调整格数、行列和画布大小。
2. 用白底黑线勾出镜头所见的轮廓和表情，留少量空间参照。优先辨清谁在画面哪一侧、看向谁、道具在谁手里。画外音留给声音，内心 OS 保持闭口。景别、时间、镜号之类的说明可放在格下或配套文字里。空间定位图指导轴线，故事版从摄影机看场面。
3. 用已确认的逐镜结构准备生图提示词和配套视频提示词。从作品根目录运行 `python3 技能目录/scripts/storyboard_sheets.py prepare 分镜.json`，输入为按播放顺序排列的 shots，使用其中的 sequence、visual_prose、actions 和已渲染的 prompt。英文任务加 `--language en`。已提供的角色、场景、道具参考图分别约束身份、布局和物件形态。
4. 按每项的 image_prompt 调用可用的生图工具，每个生成段选定一张成图，保存到本集目录，以 file_stem 命名。逐格核对出镜名单、景别、动作顺序、关键道具和轴线，逐段交付图片及 video_prompt。某段没有拿到图时标出该段，重试只补缺图。视频 prompt 保留导演决定的成片风格、动作起止、运镜轨迹、光线、声音、台词与转场，补足静态画格无法表现的部分。
