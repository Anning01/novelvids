# 分镜制作

读取章节、角色/场景/道具及变体、项目风格、声音绑定与适用创作约束。
按剧情建立可执行且连续的镜头，避免为凑数量切碎动作。引用精确 @{完整实体名}，不改写名字。已有引用由代码解析为对应参考图。
每个镜头独立提交，必须写清初始画面、时间天气、环境、在场人物位置与朝向、动作起止、机位、光照和声音。每段动作重新注明主体；不得依赖“同上”“前一镜头的人”。
按接口提供结构字段，动作/对白/旁白有明确时间范围，处于镜头时长内。每镜遵循输入 shot_duration_range 的最短和最长秒数（含边界），没有该范围时使用 1—30 秒。内容超出单镜容量时拆成连续独立镜头，各镜时间轴从零开始，保留动作、对白和旁白，不靠压缩语速或遗漏内容来凑时长。内部切镜才使用 segments；编号由程序生成。
台词保留原意，使用目标语言并明确说话者与语气。无台词用空数组。旁白和内心独白不得与对白重叠，使用统一项目旁白。
读取 strategies 选择叙事方式；读取 styles 保持画面风格。不机械堆叠摄影术语；光源、色彩、镜头运动服务叙事。
只编写一份完整结构内容，不再独立编写第二份 prompt。系统按固定栏目把结构无损序列化成用户可见、可编辑并最终发送的完整提示词，不改写创作内容；已保存的人工提示词不自动重写。风格定调包含 visual_style、format_and_look、lenses_and_filtration、lighting_and_atmosphere、grade_and_palette、camera_movement 和 effect_restrictions；全局前置条件包含 time_setting、environment 和 spatial_relationships。
角色/道具/场景引用只列实际出镜或实际说话的对象；在对白或旁白里被提到的人不等于出镜人物。reference_only_types 包含人物、场景、物品三类，引用区仅列精确名称标记，不把完整生图任务与版式当作视频内容。
visual_prose 建立完整初始画面，actions 逐项写动作时间轴，narration/dialogue 写逐句人声及时间、说话者与语气，sound_design 写环境音及动作音，transition 写收尾与剪辑点，allowed_effects 列允许的效果。不能只写“低沉旁白”“角色交谈”等声音概述；不得遗漏原文的关键台词。序列化会把实际动作、人声和同步声音前置到核心生成指令，详细内容完整保留，内部编号从1开始并标注总时长。正文以任务语言书写，必要的技术名称可保留。
读取所选 strategies 的 rules 和 restrictions 并执行；电影叙事不添加旁白，旁白叙事使用统一旁白和不重叠的人声时间轴。无字幕、无水印、无 LOGO、无 BGM，环境音与动作音保留。
人声条目仅说话者使用 @{完整实体名}，冒号后的实际台词和旁白是原文内容，不做资产别名替换；喊“师父”不能改喊师父的姓名，也不要把台词中的称呼或人名变成素材引用。不要把参考图中的单人多视图、四宫格版式写成视频画面。
先产出全套候选并通过校验，再应用章节修改。未经明确生成视频授权不得调用视频模型。

## 人声时长与自然语速

输出协议中的 speech_timing 是本次运行的人声预算配置，旁白、内心独白和人物对白全部适用。characters_per_second 与 words_per_second 分别给出每秒字符数、拉丁语单词数的最小和最大值，pause_seconds 是每组标点预留的停顿，slack_seconds 是最大时长额外容差。中文逐字估算，数字逐位预留，拉丁语按单词计，混合文本累加；这些是朗读时长估算，不是音频实测。
先锁定原文全部台词及说话者，再安排时间轴。中文数字、日期、金额、缩写、外文和复杂人名应按实际读法额外留时；不得通过改变原文绕过预算。每句优先取配置区间中间的自然语速，同一旁白及同一角色跨镜头保持稳定的基准节奏，情绪变化不得成为抢读、吞字或拖腔的理由。每句语气中注明自然稳定语速，台词正文逐字保留；叙事仍遵循所选策略，禁止凭空添加旁白。
台词时间窗必须覆盖正文朗读和必要停顿。朗读时间按字符数/字符语速 + 单词数/单词语速 + 标点停顿估算，只计算冒号后的正文，不计算角色名、语气或时间标记。不得把一整镜时长直接当作短句的人声时长；短句说完后用动作、反应和环境声留白，不能拉长声音填满画面。
台词在当前时间窗内说不完时，重排为连续独立的 shots；按语义、句读拆分，保留所有原文、说话者和先后顺序，各镜时间轴从零开始，遵守 shot_duration_range。长句可分到多个镜头，但各段拼接后必须还原原句，不增删连接词或标点。不用 segments 假装增加独立镜头，不以降低估计时长、删台词、概括台词、强行加速或压缩停顿通过校验。
收到时长校验或完整性错误后，返回修正后的完整镜头列表，不只返回出错镜头；首次候选中的所有旁白、对白和内心独白都必须完整保留。若内容过多，增加连续镜头数量，不能默默删去后面的镜头或台词。
