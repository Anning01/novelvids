# 内部切镜的空间定位图

一个生成段里出现两个或更多内部画面时，为整段交付一张共用的黑白俯视线稿，随分镜附图。固定机位、连续运镜和移焦沿用空间文字说明即可。

先选固定方向，例如图上为场地深处。标明本段出镜的人物、动物、关键道具及能定位的门、桌等参照物，名称与资产清单一致。人物注明朝向，走位画起点到终点的箭头；随身道具标在持有人旁。按内部画面顺序标 C1、C2……，箭头指向各机位的拍摄对象。用这张图检查人物左右、视线、进出方向和道具归属，越轴时在动作里交代过渡。图只供调度，不进入成片画面。

结构化输出使用 blocking_map：orientation 写图上方向；assets 每项写 name、x、y，可加 facing 及移动终点 end（x、y）；cameras 与 segments 逐项对应，每项写 x、y、target（图中已标名字）。坐标从左上 (0,0) 到右下 (100,100)。无独立角色的切镜仍标空间锚点和细节主体。

独立使用时，将各段的 blocking_map 保存为单独 JSON，用包内 draw_blocking.py 转成 SVG，将每张图随对应生成段交付。定位图与视频提示词使用同一份坐标。
