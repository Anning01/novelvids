# 按目标视频模型交付提示词

先完成并保留导演确认的通用分镜、八栏视频提示词和对应的素材关系。在提示词创作或改稿的最后一步，按本次实际选用的视频模型分流。助手自己的文本模型不参与选择。

从作品根目录运行 `python3 技能目录/scripts/select_video_optimizer.py --model 模型类型`。本次已指定的模型优先；省略参数时读取作品的 `novelvids.config.json` 中的 `video_model_type`。没有选择或没有匹配的专用技能时，直接交付通用稿。两个创作阶段共用同一份模型映射。

命中 `optimize` 时，读取返回的专项技能入口，调用该技能逐段生成一份可提交的专项 Prompt。输入为已确认的通用稿、导演保留的原话和时间线、当前生成模式，以及实际选中的参考素材及职责。有空间定位图时将其列为本镜图片输入，引用它指导走位、朝向和机位轴线。故事版作为本段构图参考；人物、场景及声音各用已选的对应素材。保留原稿的 @{资产名} / @{资产名#形态名} 身份标记，不能改成普通名称。取得本次真实图片提交顺序后可同时声明供应商编号；没有图片的资产继续保留身份标记，以便发送文字设定，不得虚构参考图。交付前对照说话者、出镜范围、道具状态及切点。

开始优化前记下作品、集、稳定镜头 ID、目标模型与该镜通用底稿，交付时把结果写回同一镜 drafts[模型标识]，逐字保留底稿。外来专项稿若只带旧底稿，先在对应集内按完整底稿唯一匹配镜头；缺失、同稿多镜或与指定 ID 不符时保留待确认。分镜独立包中可运行 `python3 技能目录/scripts/attach_shot_draft.py storyboard.json --shot-id 稳定镜头ID --model 模型标识 --source 原通用稿.txt --draft 专项稿.txt`。没有旧镜头 ID 时省略该参数，由同一集内唯一匹配的通用稿定位。

分镜阶段已产出对应专项稿，且底稿、模型、模式和素材关系均相同时，视频阶段直接复用；任一项变动，用通用稿重新优化。只要求沿用已确认提示词生成时，提交用户确认的版本。

返回 `missing` 时交付通用稿，说明目标模型的专项技能可单独安装到当前作品。

## Seedance 2.0

标准版、Mini 和 Fast 共用火山方舟的 `sd2-pe`。专项稿标记用户选中的具体型号，按本次上传顺序使用 `@图片N`、`@视频N` 和 `@音频N`。镜头时长和可用素材类型取当前型号配置。

```sh
npx --yes skills@latest add "https://arkdocs.tos-cn-beijing.volces.com/skills/" --skill sd2-pe --agent codex --yes
```

## Seedance 2.5

火山方舟官方技能为 `sd25-pe`。

```sh
npx --yes skills@latest add "https://arkdocs.tos-cn-beijing.volces.com/skills/" --skill sd25-pe --agent codex --yes
```

首次安装调试的官方版本为 0.1.1。官方技能单独由上述来源安装，交付的是文本；视频提交仍走原有生成流程。

## MiniMax H3

官方 H3 与 AutoDL 的 H3 工作流共用 `h3-prompt-writing`。根据本次渠道支持的模式和实际附带的素材，选官方基础文本／关键帧规范或全参考规范。角色设定图用于外观，故事版用于构图；只有指定为首帧或尾帧的图才约束对应时刻。仅声音出场的人物按声源位置和时间写入声音，媒体编号对应本次实际附件。

专项稿用英文描述画面和声音，台词、歌词和可见文字保留原语言。实际时长、切点、配乐沿用本镜确认稿。

```sh
npx --yes skills@latest add https://github.com/MiniMax-AI/MiniMax-H3 --skill h3-prompt-writing --agent codex --yes
```

## Wan 3.0

项目模型 `wan_3`（`wan3.0-video`）使用 `wan3-pe`。把所取得的 `wan3-pe/SKILL.md` 放入作品的 `.agents/skills/wan3-pe/` 即可安装。

按原稿语言交付五段式请求，分别整理核心任务、剧情、声音、镜头与约束、负面提示。沿用确认稿的动作和对白，按本次上传顺序在图片、视频、音频三类中分别编号，说明每份参考素材在何处生效。画幅与总时长作为生成参数单独传递。
