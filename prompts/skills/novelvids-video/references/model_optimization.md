# 按目标视频模型交付提示词

先完成并保留导演确认的通用分镜、八栏视频提示词和对应的素材关系。在提示词创作或改稿的最后一步，按本次实际选用的视频模型分流。助手自己的文本模型不参与选择。

从作品根目录运行 `python3 技能目录/scripts/select_video_optimizer.py --model 模型类型`。本次已指定的模型优先；省略参数时读取作品的 `novelvids.config.json` 中的 `video_model_type`。没有选择或没有匹配的专用技能时，直接交付通用稿。两个创作阶段共用同一份模型映射。

命中 `optimize` 时，读取返回的官方技能入口，调用该技能逐段生成一份可提交的专项 Prompt。输入为已确认的通用稿、导演保留的原话和时间线、当前生成模式，以及实际选中的参考素材及职责。故事版作为本段构图参考；人物、场景及声音各用已选的对应素材。沿用已有素材标记，只有取得本次真实提交顺序才把资产名换成供应商编号。交付前对照说话者、出镜范围、道具状态及切点。

通用稿与专项稿并存，专项稿标记目标模型。分镜阶段已产出对应专项稿，且底稿、模型、模式和素材关系均相同时，视频阶段直接复用；任一项变动，用通用稿重新优化。只要求沿用已确认提示词生成时，提交用户确认的版本。

Seedance 2.5 对应火山方舟的 `sd25-pe`。返回 `missing` 表示本项目尚未安装，先保留通用稿并告知缺少的专项技能。项目安装命令：

```sh
npx --yes skills@latest add "https://arkdocs.tos-cn-beijing.volces.com/skills/" --skill sd25-pe --agent codex --yes
```

首次安装调试的官方版本为 0.1.1。官方技能单独由上述来源安装，交付的是文本；视频提交仍走原有生成流程。
