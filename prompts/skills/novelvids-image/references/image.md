# 图片制作

读取目标资产、形态、已有提示词、项目比例与风格、参考图和所选模型能力。
已有完整提示词必须原文提交。为空或明确要求编写时，输出一个完整、可独立执行的提示词并保存版本。

同一已确认风格范围内，单人、群像、形态、场景与道具共用该画法。优先取当前世界、场段或形态明确指定的风格；project.image_style 是项目已选画法，按它的适用范围使用。读取 styles 中对应 key 的完整渲染要求（自定义风格优先）。将人物比例、五官造型、皮肤着色、材质与光影要求一致地写入每份完整提示词，不能只写风格名称或“PBR”。年龄、皱纹、情绪与人数只改变内容，不改变项目的渲染风格；不能因版式不同自行切换真人摄影、国风 CG 或夸张卡通。风格定义画法；时代、服装、发型与建筑仍遵循故事和已确认设定。
有参考图时，在完整提示词中写清每张图用于人物身份、画风或空间布局；风格参考不复制其中的人脸。复用同一角色需保留其已确认形象；多人同框需要明确成员及各自的参考图，独立“同事”群像不自动包含项目中所有主角。仅有文字或风格 key 时不能声称已锁定人脸一致性。

角色默认使用同一人物上半身正面平视特写与全身正、侧、背三视图：按项目比例构图，左侧约40%为胸部以上特写，清楚展示五官、发型、上装和配饰；右侧约60%依次展示正面、侧面、背面完整全身，头顶与鞋履不裁切，三个视角的体型、服装结构、配色和配饰一致。中性浅灰白无缝摄影棚背景、无环境元素、无墙角和地平线，仅保留浅接触阴影，无分割线、无文字、标签、Logo和水印。群像使用同一张多人关系参考图，写清人数规模、成员的相对位置和体型高矮关系，完整展示服饰轮廓、避免互相遮挡脸部与主要识别特征；使用中性浅灰白无缝背景与轻接触阴影，无文字水印，不套用单人三视图。
场景参考图是一张用于视频制作的四格电影场景图：2×2等大画面，左上正面、右上高位俯瞰、左下反向、右下侧向，均使用有纵深的透视镜头。同一空间的四个机位保持建筑、固定陈设、布局、比例、材质、天气和光源位置一致，四格都是空场景，只绘环境与固定陈设。排除人物、动物、群像、临时道具及任何角色的影像；参考图里即使有角色，也只取环境。反向视角移动机位，建筑与陈设保持原位。每格环境画面铺满到边缘，四格紧贴，只用细分隔线区分；不要留白、外框、圆角相框或标题栏，不画文字、视角名称、编号、图例、Logo和水印；不要建筑制图、正交投影、平面图或带注释的设计展示板。必须把这些版式要求写进保存的完整提示词，不能只写“四视图”让模型自行决定排版。室内与室外场景均遵循该规则；已配置固定资产协议时必须保留协议版式，用户补充要求只改变允许的设计内容；未配置固定协议时才可按用户要求调整版式。
道具写明轮廓、比例、材质、颜色、结构、纹样、磨损和识别特征，不虚构品牌和文字。
项目封面严格使用任务输入 aspect_ratio 的画幅和构图，只有缺失比例时才使用2:3；横屏、竖屏和方形均为完整电影主视觉，不裁切或拉伸成竖版。突出主要冲突与氛围，无标题、文字、Logo、水印和边框。
将所选风格与版式写进完整提示词，不依赖生成工具再次补充。模型限制以能力接口为准。
提交后记录真实任务ID，等待后台结果。没有生成请求时，仅保存设计。

修改现有图像提示词时区分画面表现和资产设定。若只要求调整光线，就保留人物身份、服装、画幅、参考图用途和排版，交付更新后的完整提示词。用户只要求改提示词时，到交付文本为止。
