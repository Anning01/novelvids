# 图片制作

按本次场次定位目标资产和形态，读取已有完整提示词、适用的风格、画幅与参考图。用户直接给出的设定也可作为输入。
直接出图时原样使用该形态已确认的完整提示词。编写或改稿时按任务语言交付完整提示词；只改光线就只动光线相关描述，保留该形态的身份、服装、画幅、参考图用途和版式。只要提示词时，到交付文本为止。

同一已确认风格范围内，单人、群像、形态、场景与道具共用该画法。优先取当前世界、场段或形态明确指定的风格；project.image_style 是项目已选画法，按它的适用范围使用。读取 styles 中对应 key 的完整渲染要求（自定义风格优先）。将人物比例、五官造型、皮肤着色、材质与光影要求一致地写入每份完整提示词，不能只写风格名称或“PBR”。年龄、皱纹、情绪与人数只改变内容，不改变项目的渲染风格；不能因版式不同自行切换真人摄影、国风 CG 或夸张卡通。风格定义画法；时代、服装、发型与建筑仍遵循故事和已确认设定。
局部改稿沿用已确认的完整风格词原文；年龄、体态和参考图的适用部位写在对应的角色描述里，照片中的皮肤与光照按项目画法重新表现。新写或修改画法前，若当前世界或场段尚无已确认风格，先请用户选定这一范围的画法。
有参考图时，按实际附图顺序写明每张图对应的对象和取用部位。脸型、体态、服装、材质和布局可以各有来源；只指定脸和体态时，衣着沿用本场形态。风格参考不复制其中的人脸。多人同框需要明确成员及各自的参考图。仅有文字设定时直接描述外观。

角色默认使用同一人物上半身正面平视特写与全身正、侧、背三视图：按项目比例构图，左侧约40%为胸部以上特写，清楚展示五官、发型、上装和配饰；右侧约60%依次展示正面、侧面、背面完整全身，头顶与鞋履不裁切，三个视角的体型、服装结构、配色和配饰一致。中性浅灰白无缝摄影棚背景、无环境元素、无墙角和地平线，仅保留浅接触阴影，无分割线、无文字、标签、Logo和水印。群像使用同一张多人关系参考图，写清人数规模、成员的相对位置和体型高矮关系，完整展示服饰轮廓、避免互相遮挡脸部与主要识别特征；使用中性浅灰白无缝背景与轻接触阴影，无文字水印，不套用单人三视图。
场景参考图是一张用于视频制作的四格电影场景图：2×2等大画面，左上正面、右上高位俯瞰、左下反向、右下侧向，均使用有纵深的透视镜头。同一空间的四个机位保持建筑、固定陈设、布局、比例和材质一致，色调、光线与天气按该资产的设计意图表现，四格都是空场景，只绘环境与固定陈设。排除人物、动物、群像、临时道具及任何角色的影像；参考图里即使有角色，也只取环境。反向视角移动机位，建筑与陈设保持原位。每格环境画面铺满到边缘，四格紧贴，只用细分隔线区分；不要留白、外框、圆角相框或标题栏，不画文字、视角名称、编号、图例、Logo和水印；不要建筑制图、正交投影、平面图或带注释的设计展示板。室内与室外场景都可采用这个参考版式。描述实际使用的机位与构图，并按用户要求调整。
编写多视角场景稿时，用固定参照物交代各机位的朝向和可见范围。拿到成图后逐格对照出入口与主要陈设，特别看换机位后它们是否仍在同一面墙、同一端。出现错位就指出具体格子和位置，供定点修图。
道具图展示本次形态的完整物体，交代轮廓、比例、材质、颜色、结构、磨损和识别特征。持有者和使用动作留给分镜。
项目封面严格使用任务输入 aspect_ratio 的画幅和构图，只有缺失比例时才使用2:3；横屏、竖屏和方形均为完整电影主视觉，不裁切或拉伸成竖版。突出主要冲突与氛围，无标题、文字、Logo、水印和边框。
将所选风格与版式写进完整提示词，不依赖生成工具再次补充。模型限制以能力接口为准。
工具直接返回图片时交付成图；异步提交时记录返回的真实任务 ID。
