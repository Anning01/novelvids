# 从小说或梗概改编短剧

先按用户给出的集数、时长、受众、叙事视角和可改编范围取舍素材。只有原文时从实际出现的人物与矛盾起笔；只有点子时，可以在约定范围内创作人物和事件。保留原文中的专名、关键事实、已指定的台词和揭示顺序。把无法从素材确定、又会改变动机或结局的选择明确列为改编决定。

先找到本集要发生的一次变化：谁想达到什么目的，谁或什么阻止了他，结尾发生了什么，使下一步行动不可避免。按因果组织场次。进入场景时尽量靠近第一次有代价的选择，离开时留在决定、发现或关系变化处。用可见行动和可听声音表达心理；保留沉默、迟疑或误解的空间，不用旁白重复画面。

交叉剪辑或闪回注明进出点。按用户时长给场次分配时间，长台词按自然语速试读；超时先压缩重复信息，再调整场次。

改稿时先识别用户指定的场次和要改变的效果，保留已确认的人物关系、前后场因果与原句约束。完成后检查每场是否让信息、人物关系或行动至少一项发生变化，确认演员能从文本判断自己要争取什么。

## 默认交付的分场格式

集标题写成「第1集　集名」。场头按「集号-场号　地点　内/外　时段」书写，例如「1-2　渡口候船室　内　黄昏」。场号在集内递增，地点或叙事时间切换时换场；同场内人物进门、转身、开口可以直接续写。修订引用已有场号，只在真正拆场或并场时注明对应关系。

场头下面写「出场：」，列全本场画面中实际出现的人物、动物和群像，包括沉默者、昏迷者、被牵引或驮着人的动物。原文以群体出现时沿用群称。只拍场景或物件时写「出场：无」。整场只闻其声的角色另列「仅声音：」，没有则省略。用剧本当前已揭示的姓名或稳定称呼；提到的亲属、心声、音效和无名旁白都不因此成为出场人物。一个角色在本场先从门外喊话、随后入画，只列在「出场」，前一句仍按画外声标注。

有影响剧情或跨场接戏的实物时，在名单后加「关键道具：」，按稳定名称列出。数量、缺损、持有人或位置的变化写在对应的 △ 动作里；跨场沿用同一名称。日常陈设照常写进画面，只有它的状态或使用会影响剧情时才列入关键道具。

按动作和话语实际发生的顺序逐行写。普通对白写「角色名：台词」，默认角色开口。同一个人一口气说完的话可放在同一行；从心声转为说出口、被动作打断或语气明显转折时另起一行。

表演提示写在角色名后的括号里。只有读法影响这场戏时才加，选演员能做、配音能读出来的变化：怕被听见时压低声音，壮着胆子探问时放轻句尾，一边走一边责备自己时低声念叨。情境已经清楚的问答直接写台词。

先看原文怎样交代这句话。“嘴里念叨”可写「角色名（低声自语）：台词」；“想质问却没敢说出口”可用一个欲言又止的动作，若让观众听见那句心声，就写「角色名（OS）：心声」。声音小、自称其名或没人回应，都可能是实际说出了声。

| 写法 | 这行交付给制作的内容 |
| --- | --- |
| △ 可见动作 | 写演员能做、观众能看见的变化，包括与道具的交互。动作发生在对白中间，就插在对应两句之间。 |
| 角色名：台词 | 普通开口对白，制作时对口型。如需特定读法写「角色名（压低声音）：台词」。配音只读冒号后的文字。 |
| 角色名（OS）：心声 | 本项目用 OS 专指内心独白。观众听得见，角色嘴唇不动，同场人物听不见。 |
| 角色名（画外）：台词 | 此刻说话人不在画面里，声音实际来自门外、隔壁、电话等。谁能听见取决于现场声源，画内听者可以回应。 |
| 旁白：叙述 | 给观众的叙述声。只在需要叙述或用户指定时使用；已知叙述者可写「角色名（旁白）：」。 |
| 【音效】声音 / 【屏显】载体：文字 | 按需单独成行。音效用于关键声音，如落锁声让人停步；屏显用于观众必须读清的文字，写出载体与确切内容。 |

普通对白在中英文稿中都省略发声标签。英文任务沿用同一场号、△ 动作标记及本项目的 OS 约定，画外说话用 Off-screen，旁白用 Narrator。用户指定交付模板时采用其标记，并保持这些声音含义清楚一致。

### 一场戏的写法

```text
1-1　渡口候船室　内　黄昏
出场：阿岚、船工、驮马
仅声音：守闸人
关键道具：铜钱

△ 阿岚牵着驮马来到窗口。船工把她递来的两枚铜钱推回去。
守闸人（画外）：落闸了！
△ 阿岚捏起一枚，又把另一枚推回去。
阿岚（OS）：回来的船钱怎么办？
阿岚（压低声音）：先把马送过去。
船工：那你呢？
```

交稿前，把每场的原文、动作行和场头名单对一遍。谁出镜，谁只出声？谁拿走了道具，下一场还剩多少？把漏掉的人物、动物、群像和关键道具补到对应场次。

## 本集时长与节奏

读取 episode_pacing。compact 压缩过渡与重复反应；fast 用主要动作和对白推进；smart 按内容自然估时；slow 给重要反应留白；detailed 展开有叙事作用的细节。按自然语速试读对白和 OS，能与台词同时发生的动作不重复计时。

max_seconds 缺省或为 null 时，本集按剧情自然展开，省略时长上限行。仅在提供 max_seconds 数值时，将「本集时长上限：90 秒」放在集标题下一行，数值使用用户设置的 max_seconds。英文写作使用「Episode duration limit: 90s」。时长与用户指定原话冲突时，优先压缩其他可省内容。
