# 从小说或梗概改编短剧

先按用户给出的集数、时长、受众、叙事视角和可改编范围取舍素材。只有原文时从实际出现的人物与矛盾起笔；只有点子时，可以在约定范围内创作人物和事件。保留原文中的专名、关键事实、已指定的台词和揭示顺序。把无法从素材确定、又会改变动机或结局的选择明确列为改编决定。

先找到本集要发生的一次变化：谁想达到什么目的，谁或什么阻止了他，结尾发生了什么，使下一步行动不可避免。按因果组织场次。进入场景时尽量靠近第一次有代价的选择，离开时留在决定、发现或关系变化处。用可见行动和可听声音表达心理；保留沉默、迟疑或误解的空间，不用旁白重复画面。

交叉剪辑或闪回注明进出点。按用户时长给场次分配时间，长台词按自然语速试读；超时先压缩重复信息，再调整场次。输出可直接阅读的剧本，只有用户要求分镜时才继续拆镜。

改稿时先识别用户指定的场次和要改变的效果，保留已确认的人物关系、前后场因果与原句约束。完成后检查每场是否让信息、人物关系或行动至少一项发生变化，确认演员能从文本判断自己要争取什么。

## 默认交付的分场格式

集标题写成「第1集　集名」。场头按「集号-场号　地点　内/外　时段」书写，例如「1-2　渡口候船室　内　黄昏」。场号在集内递增，地点或叙事时间切换时换场；同场内人物进门、转身、开口可以直接续写。修订引用已有场号，只在真正拆场或并场时注明对应关系。

场头下面写「出场：」并列出本场实际可见的人物，包括沉默、昏迷或一闪而过但确实出现的人。空镜写「出场：无」。整场只闻其声的角色另列「仅声音：」，没有则省略。用剧本当前已揭示的姓名或稳定称呼；提到的亲属、心声、音效和无名旁白都不因此成为出场人物。一个角色在本场先从门外喊话、随后入画，只列在「出场」，前一句仍按画外声标注。

按动作和话语实际发生的顺序逐行写；同一人从想法转为开口时另起一行。四种声音的区别是观众听见谁、戏里的人能否听见、说话的嘴是否在画面中：

| 写法 | 这行交付给制作的内容 |
| --- | --- |
| △ 可见动作 | 写演员能做、观众能看见的变化，包括与道具的交互。动作发生在对白中间，就插在对应两句之间。 |
| 角色名：台词 | 角色在画面中实际开口。必要的表演提示放在名字后的括号里，例如「船工（压低声音）：上来。」配音只读冒号后的文字。 |
| 角色名（内心）：心声 | 观众听得见，角色没有开口，同场其他人听不见。心理能通过表演成立时，直接写动作即可。 |
| 角色名（画外）：台词 | 此刻说话人不在画面里，声音实际来自门外、隔壁、电话等。谁能听见取决于现场声源，画内听者可以回应。 |
| 旁白：叙述 | 给观众的叙述声。只在需要叙述或用户指定时使用；已知叙述者可写「角色名（旁白）：」。 |
| 【音效】声音 / 【屏显】载体：文字 | 按需单独成行。音效用于关键声音，如落锁声让人停步；屏显用于观众必须读清的文字，写出载体与确切内容。 |

中文稿直接写「内心」「画外」「旁白」，避免裸用含义不一的 OS/VO。英文任务沿用同一场号和 △ 动作标记，场头、人物名单、对白和标签用英文，声音分别写作 Inner voice、Off-screen、Narrator。用户指定交付模板时采用其标记，并保持这些声音含义清楚一致。

### 一场戏的写法

```text
1-1　渡口候船室　内　黄昏
出场：阿岚、船工
仅声音：守闸人

△ 船工把两枚铜钱推回窗口。阿岚的手还摊在窗台上。
守闸人（画外）：落闸了！
△ 阿岚捏起一枚，又把另一枚推回去。
阿岚（内心）：回来的船钱怎么办？
阿岚：先送他过去。
```

交稿前按场核对：可见人物是否齐全，只有声音的人是否被误列为出镜，动作和台词能否分开提取，转场后的道具仍在谁手上。剧本到可拍摄的场次、动作和声音为止；景别和运镜由分镜环节决定。商业分集稿如需标关键集、付费卡点、集尾钩子或下集预告，另放在分集说明中，保持剧本正文可直接交给演员和下游制作。
