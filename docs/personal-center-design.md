# 猫影短剧个人中心需求稿

状态：首版本地实现 · 2026-11-05

## 页面目标

打开个人中心，用户应当能看清三个问题：我用什么账号登录、我在哪个团队工作、我在这个团队花了多少钱。首屏优先展示当前团队和下一步操作。完整账单、团队管理和作品详情继续使用已有页面。

当前页面没有把「当前团队」和「已加入的团队」区分开。器灵生成的系统用户名在页首占据显眼位置，绑定状态反而藏在下面。退出登录也不需要占一整行的主要位置。

## 版式

桌面保留应用侧栏，内容区最大宽度约 1040px。顶部是一张简洁的身份栏。下方左侧较宽，放当前团队和已加入的团队。右侧放消费摘要与账号安全。手机端按「身份 → 当前团队 → 消费 → 其他团队 → 安全与帮助」依次排列。沿用产品现有深浅主题与按钮、卡片样式。

## 首版内容与交互

| 区块 | 展示内容 | 操作与边界 |
| --- | --- | --- |
| 账号身份 | 头像、昵称、注册日期。账号密码版可显示真实用户名，器灵版显示「器灵已绑定」或「待绑定」 | 优先展示已有头像，缺失时使用昵称首字。系统生成的 qiling-… 用户名不作为公开昵称展示。平台管理员徽标单独显示。 |
| 当前团队 | 团队名称、个人团队标记、成员角色、团队状态 | 「进入项目」打开该团队项目列表。「成员管理」只对当前团队管理员显示。平台管理模式明确显示「平台管理」，不把它当成一个团队。 |
| 团队列表 | 每个团队的名称、本人角色、加入日期和状态，标明正在使用的团队 | 复用侧栏切换逻辑。切换后刷新项目入口和消费范围。停用的团队或成员身份不可切换，并解释原因。 |
| 我的消费 | 当前团队的本人累计消费。有个人限额时展示限额和可用额度。团队余额独立标注并按角色展示 | 分开标注「个人限额」「团队余额」和「本人累计消费」，避免误读。成本入口复用现有权限，管理员进入团队成本页，创作者进入个人成本页。 |
| 登录与安全 | 登录方式、绑定状态及退出登录 | 开源版保留修改密码。器灵版提供现有的绑定入口，仅在尚未绑定时显示。已绑定时显示状态。首版不新增解绑、改绑。 |
| 协议与帮助 | 用户协议、隐私政策、账号与数据申请方式 | 配置完整时链接至已发布文本。申请入口采用真实运营联系渠道，文案写「提交申请」，不做一键注销承诺。 |

## 个人团队规则

- 新用户注册时自动获得一个个人团队，注册者拥有该团队并担任管理员。一个账号只拥有一个个人团队。个人中心不显示「创建团队」。
- 加入其他团队须通过他人发出的有效邀请链接。页面只说明入口，不提供直接搜索加入。
- 已有团队或消费记录的账号继续使用原归属。为符合条件的存量空账号补建团队时，先核对身份、已有归属及停用状态，避免重复创建或绕过停用限制。
- 团队角色与平台角色分开。超管切到团队后，项目、费用和团队操作按其团队身份展示。

## 状态与验收

- 新账号进入时能看到个人团队、「管理员」和「进入项目」。零消费显示 ¥0.00。加载失败显示重试，不能把失败误当成零消费或无团队。
- 同时属于个人团队和其他团队时，当前团队标记、角色、个人消费及项目入口随切换更新。受邀的团队始终显示实际角色和加入时间。
- 查看者无法打开团队管理或越权查看账单。管理员与创作者看到的成本范围与现有成本页一致。
- 器灵版和账号密码版分别展示适合自己的安全操作。器灵账号的系统用户名不挤占头像旁的空间。
- 桌面和窄屏均能读取长昵称、长团队名和完整金额。深浅主题、键盘焦点、加载、错误和停用状态清晰可辨。
