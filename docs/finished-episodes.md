# 作品库

- 导航「作品库」集中显示已完成合成的项目。一个项目一张作品卡片，独立详情页显示剧集和合成版本。
- 合成成功后自动入库，旧合成记录也直接收录。可在作品详情维护标题、简介、标签和封面。作品类型沿用创作时保存的风格或项目类型。
- 作品默认使用第一集成片首帧。编辑资料可选用其他剧集首帧。历史成片首次读取封面时按需补取。
- 项目统计按每集最新成功合成版本的实际时长累计。

## 发布与访问（需人工审核）

- 启动时安全创建 `portfolio_works` 和 `portfolio_episodes`。公开剧集引用已存在的成片，作品档案写入时检查版本以防覆盖其他人的更新。
- 创作者可整理团队作品并提交审核。团队管理员可通过审核、公开、下架和设置推荐顺序。查看者只读，超级管理员可跨团队管理。
- 公开后，访客可通过链接访问作品资料和管理员所选的剧集版本。重新合成保留当前公开版本。下架关闭公开接口并移除首页推荐。
- 视频由应用核验访问权限后提供，公开页面使用支持分段读取的媒体接口。已有历史单集发布接口保留兼容，项目归档到新作品档案后由作品级公开规则接管。
- 首页推荐设置保存在作品档案中。

## 验证

- 鉴权和公开边界：`AUTH_ENABLED=true uv run pytest test/test_auth/test_portfolio.py test/test_auth/test_finished_episodes.py --no-cov`。
- 前端：作品列表、详情页、封面和项目入口相关测试，以及类型检查和生产构建。
