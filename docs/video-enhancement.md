# 视频画质增强：AI MediaKit

[返回首页](../README.md) · [English](video-enhancement.en.md)

1. 在设置的「视频画质增强」中填写具备 AI MediaKit 权限的 Key，核对价格后启用；仍需启用创作助手及支持工具调用的助手模型。图片/视频生成配置与增强配置相互独立。运行时从模型配置表读取 Key、地址和价格，无需配置 `MEDIA_KIT_KEY` 环境变量。
2. 单条视频：分镜预览保留「高清化」入口。无限画布从视频输出端口拖线到空白处，选择「高清视频」，直接创建新视频卡片，卡片使用画布深色背景，中央仅保留清晰度选择与增强操作；服务选择收进选中工具栏。确认费用后，进度与完成视频也在该卡片显示，无须中间转换器或导出弹窗。提交后来源、服务与清晰度锁定，连线和撤销不能改写任务；换参数请删除卡片或重新拉线创建，删除卡片不会删除已保存的视频。无需等待其他分镜或整集完成。视频页保留播放和下载，不再显示整集「高清成片」准备区域；整集导出接口及历史记录继续保留。
3. 仅允许清晰度提升：按真实文件短边检查，禁止1080p→1080p或降级。画布可选后台启用并配置价格的720p、1080p、2K、4K档位。旧配置继续保留原1080p档位；在设置中编辑增强服务、勾选新增档位并核对价格后生效。画布菜单会展示全部支持档位，并区分“服务未启用”和“不高于原片”，不会因展示选项而自动改价或启用服务。当前MediaKit大模型服务仍只接收最高1080p的原片，因此可做1080p→2K/4K，不能把2K输出继续作为输入；需要4K时直接从符合限制的原片生成。单条视频高清化成功后自动设为分镜当前视频，预览、下载和后续合成都使用高清版，原视频保留在生成历史中。增强期间若已换片或选中同一来源的更高分辨率结果，则只保存高清历史，不覆盖新选择；历史高清结果也可免费点击「设为当前视频」，不再生成或收费。整集导出仍是独立产物，不替换某个分镜。
4. 核对冻结版本、目标清晰度、实际时长和费用后确认增强。保持原比例和帧率，原片与高清版分别保留；已成功增强的相同版本直接复用，重复下载不计费。也可在助手中提出需求，核对具体版本和报价后确认。
5. 后台负责查询、保存与结算；关闭浏览器不影响收集。下载失败只重试保存，不重新增强；提交结果不明时待人工核对，不自动重复收费。更换镜头后需准备新版本。
6. 在单条参数或批量生成窗口开启「生成后自动高清化」，可以一次提交视频生成与成功后的增强；费用分别展示与入账。章节顶部「批量参数」可修改模型、返回尾帧、比例、分辨率和高清化，并保存为本项目后续章节默认值。保存不触发生成，已有视频不被重新处理。详见[项目视频默认参数与自动高清化](video-generation-defaults.md)。

分镜高清化使用单层弹窗：左侧预览当前视频，右侧选择后台已启用的清晰度，底部显示报价并点击「确认增强到…」。报价只对当前来源、服务与清晰度有效，确认后才提交收费请求。版本记录默认折叠，可以下载历史版本、使用已有高清版或恢复原视频。已有1080p视频可选择更高且满足服务输入限制的目标；不能重复增强到相同清晰度。设置页保留服务、清晰度与价格配置，存储实现等技术说明保留在本文档。

打开弹窗先展示已有封面和可播放视频，版本记录、增强配置及来源校验在后台读取。已有准备版本直接读取；没有版本时只准备一次，读取失败需明确重试。任务轮询只读取状态，不重复读取模型配置或提交增强；关闭弹窗后仍跟踪当前任务，直到完成并通知分镜页面刷新。预览直接播放当前视频地址，不以整段下载完成为前提；下载仍使用原权限与下载接口。页面离开后停止前端轮询，后台任务继续处理，再次打开可恢复进度。首次来源校验仍需要实际读取媒体，不保证核对或供应商处理立即完成。

增强按供应商报告的实际时长、输出规格和管理端价格单独记录「画质增强」用量；报价不是供应商最终账单。缺少用量时标记待核对，不视为已核实零费用。应用验证输出尺寸、时长与帧率，并保留原音轨；画质、人物细节及长期稳定性仍以实际样片为准，不保证固定节省比例。

本地成片保存在 `CHAPTER_EXPORT_PATH`（默认 `./data/chapter-exports`），必须位于公开 `MEDIA_PATH` 之外；下载经过项目权限检查。默认 Docker 的 `data` 挂载已覆盖此目录，自定义路径需自行持久化和备份，不能给它配置公开静态目录。供应商通过 MediaKit 临时上传读取本地成片，无需开放本机端口；OSS沿用现有私有存储及签名地址。不要把密钥写进 Skills、任务或源码。

开发与验收的完整规则、恢复及回退说明见[开发计划](superpowers/plans/2026-10-27-mediakit-video-enhancement.md)和[执行与验收记录](superpowers/verification/2026-10-27-mediakit-video-enhancement.md)。支持单条已生成视频与章节成片增强。画布提供可选清晰度的新视频卡片；相同来源、服务和清晰度共用任务与结果，逐镜头自动增强仅在用户明确开启后执行，不自动插帧。能力与价格参考[官方API说明](https://docs.volcengine.com/docs/intelligent-processing/enhance-video-generative?lang=zh)和[官方计费说明](https://docs.volcengine.com/docs/Intelligentprocessing/video-tool-billing?lang=zh)。

## 验收范围

只提升部分分镜时，章节合成会按已选视频的最高尺寸等比例缩放并补边，保持高清片段的输出尺寸；这只是统一成片画布，不会为其他低清片段执行 AI 增强或产生额外模型费用。设为当前版本的单条高清片段沿用普通分镜视频的媒体存储与访问方式，章节导出仍保留在私有成片目录。

界面与能力配置支持720p、1080p、2K、4K。真实验收覆盖1080p和一段2K样例，尚未独立完成4K供应商输出及长片质量验收。不承诺固定降本比例或与原生高清生成等价。
