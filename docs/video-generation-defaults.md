# 项目视频默认参数与自动高清化

单条分镜的参数弹层和批量生成窗口均提供「生成后自动高清化」。选择增强服务与更高的目标清晰度后，点击生成即授权本次视频生成及成功后的增强。视频与增强分别记录用量和费用，按钮旁展示视频费用，参数区展示增强费用范围；实际增强费用按真实时长、帧率和所选服务配置结算。没有开启时维持原流程。

章节顶部「批量参数」可以统一修改本章模型、返回尾帧、比例、生成分辨率和自动高清化。勾选「保存为本项目后续章节的默认参数」后，新章节分镜继承这些值；已有分镜显式保存的参数优先，开启/关闭高清化都可以覆盖默认值。其他项目不受影响。应用参数不会修改提示词、资产关联或已有视频，不会提交收费请求。

## 数据与执行边界（需人工审核）

- `Novel.video_generation_defaults` 是新增的可空 JSON 字段。旧数据为空，自动高清化默认关闭。启动兼容只增加缺失列，不删除表或覆盖数据；上线前仍按部署规则备份数据库。
- 只读用户不能保存参数或生成；批量修改复用现有项目和团队权限，只能应用到该项目所属章节。
- 每次视频提交固定具体增强配置、目标和不含密钥的价格/能力快照。配置版本变化时拒绝沿用旧授权，需重新确认。参数保存本身不授权生成。
- 自动增强通过 `followup:auto_enhancement` 持久化回执串联原视频、准备导出和增强导出。仍使用已有助手执行路径、供应商适配、导出幂等键、权限与余额检查。后台等待不持续调用 LLM。
- 视频成功且完成结算后才进入增强。原视频失败/取消时不新增增强；已完成准备、已创建增强任务、已提交供应商的请求均复用回执，不能重放付费生成。
- 后台重新核对实际尺寸、时长、帧率、文件内容及配置。目标不高于实际短边则跳过；配置、权限、余额等变化则停止后续提交并保留原视频。
- 父运行等待增强收口，取消停止尚未执行的后续步骤。已经被供应商接受的增强继续由原收集器回收结果与费用；不能声称已撤回供应商请求。
- 增强完成沿用既有安全选择规则：当前仍为该来源且没有更新的更高版本时自动选择高清版；用户中途换片则保留历史，不覆盖新选择。原片不删除。

## 验证

定向覆盖项目/章节范围、仅参数写入、默认继承与显式关闭、重复初始化、恢复、并发回执、配置变化、等分辨率跳过、取消、结果不明、出站增强请求和结算幂等。前端覆盖三个入口、中英文、明暗主题及窄屏。PostgreSQL 18.6 上使用部署前数据库的隔离副本验证了新增可空 JSONB 列和重复启动，32 张表的原有数据校验值保持一致；新增列在安全建表检查之前补齐。自动链路的供应商请求使用模拟服务，未新发真实付费生成。

回滚代码可保留新增的可空字段，不必删列。回滚前应先停止新提交并核对已在供应商执行的增强任务；不能通过回滚或删除回执掩盖实际费用。
