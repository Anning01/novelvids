## 在线登录与首页

### 器灵微信扫码登录 / Qiling sign-in

商业站通过器灵微信授权登录；阅读并同意协议后获取二维码。

[![商业站器灵微信扫码登录入口](images/screenshots/login.jpg)](images/screenshots/login.jpg)

### 首页图片与视频创作 / Image and video creation

选择模型、画面比例、清晰度与时长，输入想法或引用素材，查看费用后提交创作。首页同时展示创作入口和已公开作品。

[![新版首页：片段创作、参考素材与优秀作品](images/screenshots/home.jpg)](images/screenshots/home.jpg)

## 从故事到分镜

### 我的创作 / My projects

项目卡片汇总创作状态、资产、成片与已入账费用，支持搜索、排序和继续编辑。

[![新版项目列表与统计卡片](images/screenshots/projects.jpg)](images/screenshots/projects.jpg)

### 故事与项目设定 / Story and production profile

在同一项目中查看剧情分析、分集正文、人物小传、视觉风格和分镜策略。

[![故事分析与项目设定](images/screenshots/novel.jpg)](images/screenshots/novel.jpg)

### 项目资产 / Project assets

角色、场景与道具按项目和章节组织，已有参考图与后续镜头共享。

[![新版场景资产管理](images/screenshots/asset.jpg)](images/screenshots/asset.jpg)

### 可编辑分镜 / Editable storyboard

按集检查镜头描述、角色引用、完整提示词、模型参数与视频结果。

[![新版故事板分镜编辑界面](images/screenshots/storyboard.jpg)](images/screenshots/storyboard.jpg)

### 创作助手 / Creation assistant

助手与分镜并排展示，可以选择作用范围、模型和修改对象，使用自然语言描述调整要求。

[![新版创作助手与分镜并排布局](images/screenshots/creation-agent.jpg)](images/screenshots/creation-agent.jpg)

### 无限画布 / Infinite canvas

在同一工作流中组织场景、角色、道具与视频镜头，查看引用连线，按需要缩放和整理布局。

[![新版无限画布与资产引用连线](images/screenshots/workbench.jpg)](images/screenshots/workbench.jpg)

## 成片与素材复用

### 作品库 / Works library

按作品归档成片，管理公开状态、审核和首页推荐。截图中的视频为已有公开示例节选。

[![新版作品库与成片归档](images/screenshots/portfolio.jpg)](images/screenshots/portfolio.jpg)

### 资源库 / Resource library

按文件夹与素材类型整理图片、视频、BGM、音效、贴纸、音色及角色资料，复用于后续创作。

[![新版统一资源库](images/screenshots/resource-library.jpg)](images/screenshots/resource-library.jpg)
