# 创作指南

[返回首页](../README.md) · [English](creation-guide.en.md)

建议从一章短文本开始：先检查分析与资产身份，再生成少量分镜。故事板和画布编辑同一份项目对象，不必重复维护设定。旧版 `.doc` 请先转为 `.docx` 或纯文本；扫描版 PDF 需先进行 OCR，本项目不把无正文的扫描页当作已解析书稿。

## 中文与英文

系统语言由管理员统一设置，影响界面及后续任务。新安装默认英文；已有配置值保留。已提交任务使用自己的语言快照，历史书稿、资产、提示词和媒体不自动翻译。英文对白和声音配置见[English production guide](english-production.md)。

## 核心功能

### 从书稿到项目

- 支持粘贴文本和上传 `docx`、`txt`、`pdf`、`md`，自动解析正文与章节结构
- Agent 模式自动完成项目分析、章节拆分与资产规划；人工模式可逐步编辑
- 项目比例、分辨率、视觉风格和分镜策略在创建时确定，并在后续页面保持一致
- 浅色/深色主题拥有独立创作页背景，界面设置本地持久化

### 重制工坊

- 支持上传单个 `mp4` / `mov` 视频、按集数命名的整套文件夹，以及选择系统内的历史项目
- 单视频最大 500 MB、最长 20 分钟；文件夹模式自动识别“第12集 / 第12话 / EP12 / E12 / 12集”等集数格式并排序
- 创建时可选择比例、清晰度和视觉风格，入口与短剧制作复用同一套创作 UI
- 后端先识别全局角色、场景和道具，再检测镜头并逐段生成专业分镜 Prompt，最终写入现有设定页、故事版与无限画布
- 拆解任务在服务端异步运行；关闭或刷新页面不会取消任务，重新进入项目可从持久化快照恢复进度
- 独立进度页通过 SSE 展示逐集、逐阶段和逐镜头进度，失败集可单独重试，成功集无需重复上传
- 视频理解模型仍作为 LLM 的“重制”能力用途配置；支持豆包关闭思考模式、受控并发、10 分钟单请求超时与安全耗时记录

### 设定资产与衍生形态

- 自动提取角色、场景、道具，并将同一实体的别名统一归档
- 角色、场景、道具三类资产可在一次批量任务中同时生成
- 支持文生图、上传图片、从音色库选择，以及参考图驱动的图生图
- 每个资产保留生成历史和当前版本；支持图片放大预览、切换当前版本与生成状态反馈
- 支持角色变装、年龄/状态变化等衍生形态；每个衍生形态可独立配置图片和音色
- 支持资产合并与章节级资产绑定，故事版与无限画布共享同一份引用关系

### 分镜策略与专业 Prompt

- 分镜策略工厂：内置「电影感叙事」和「旁白叙事」，项目创建和剧本编辑均可切换
- 旁白策略可配置统一旁白音色，并在无人物对白的时间段安排旁白或人物内心 OS
- 每个视频 Prompt 都是可独立执行的镜头任务：完整写明时间、环境、站位、动作起止和声音
- 最终 Prompt 使用 `@{资产名}` 与 `@音频N` 显式绑定角色、场景、道具和角色音色
- 高优先级核心生成指令会前置初始画面、动作、人声和同步音效，再保留详细时间轴
- 分镜 Prompt 可视化编辑，资产/音频标签可点击预览或播放；遗漏实体引用会自动补标

### 故事版与无限画布

- 故事版集中编辑分镜描述、资产、Prompt、视频参数与生成状态
- 基于 Vue Flow 的无限画布支持平移、框选、缩放、自动布局、复制/粘贴、撤销/重做、折叠、标记与视口持久化
- 无限画布可拖入参考图，接口与故事版共用多模态素材协议
- 分镜选择的模型、比例与分辨率会持久化，刷新页面不会恢复成其他模型

### 音色库与声音一致性

- 内置系统音色，同时支持用户上传 `mp3` / `wav` 参考音频
- 展示真实音频时长；长音频可通过双滑块在线裁剪并从裁剪起点试听
- 角色基础形态、每个衍生形态和项目旁白均可独立选择音色，选择后立即保存
- Prompt 中明确写出 `@音频N 对应角色 @{角色名}`，避免模型混淆声音归属
- Seedance 支持公网 URL 与本地 Base64；MiniMax 使用公网 URL/Base64；Wan3 的本地素材通过阿里云百炼临时存储处理

### 视频生成、连续性与成片

- 配置驱动的视频工厂，根据模型能力自动转换请求参数，不依赖模型名称猜测
- 支持参考生视频和首尾帧生视频；参考图片、视频、音频均有明确用途
- 单镜头可设置模型、时长、比例、分辨率、声音和尾帧衔接
- 页面通过轮询同步视频任务；重新进入章节会恢复未完成任务的查询，切回窗口会立即同步。临时断网或状态请求超时会自动重连，不重新提交生成。也可点击预览区「刷新视频状态」，无需再次生成。
- 批量生视频可统一模型、比例、分辨率并选择多个分镜；开启尾帧连续生成后按顺序逐个执行，无需值守
- 供应商未返回尾帧时，后端通过 FFmpeg 从成片提取；下一镜头自动把该图片作为首帧参考
- 忘记勾选「返回尾帧」也不用重生：在已完成视频的预览区点击「提取尾帧」，从现有视频截取并加入下一分镜参考图；随后可「下载尾帧」。此操作不调用生成模型、不产生模型费用，也不更改原视频。下一分镜尚未创建时可先下载，稍后手动添加参考图。
- 全能参考模式会上传尾帧图片，并把首帧说明绑定到最终图片编号；它提供衔接参考，不保证严格锁定首帧。需要严格锁帧时，使用模型支持的首帧／首尾帧模式；两种模式不能混传。旧的 `first_frame_reference` JSON 在提交时兼容转换，不批量重写已保存分镜。
- 异步任务由后端定时收口，关闭浏览器或刷新页面后仍会继续查询供应商结果
- 视频页可选择「分镜文件 ZIP」或「合并成片 MP4」，默认 ZIP。分镜包由浏览器直接读取 OSS 视频，按 `001-分镜1.mp4` 等序号打包，保留当前选中的原视频，不请求后端合成或模型；缺失镜头不包含在包内。可查看进度并取消。
- 只有选择「合并成片 MP4」才使用服务器 FFmpeg；本地合成中断后可点击下载恢复，收费生成的外部提交保护不变。合成素材暂存媒体磁盘，逐段处理并限制编码线程，成功后才替换成片。
- 本集预览播放当前镜头时会提前缓冲下一段视频，切换时复用播放器；尚未生成的分镜仍按原时长显示黑屏占位。网络太慢、下一段尚未准备好时会保留上一帧并显示缓冲提示，不自动合成或重新生成视频。
- 全局媒体库支持图片、视频、音频预览和生成版本管理

浏览器打包要求对象存储允许网页来源的跨域 GET。支持文件保存 API 的浏览器直接写入磁盘，其他浏览器在本地暂存 ZIP 后下载；视频已压缩，ZIP 不重复转码。当前使用 ZIP32，整包须小于 4 GiB，超出时可从分镜生成记录分别下载。此功能不经过应用后端代理文件。

### 多模型与成本计费

- 文本、图像、视频任务分别配置模型，支持多个配置并行启用与页面选择
- 模型能力、默认参数、素材限制、协议和价格以后端配置为唯一事实来源
- 每次调用记录 token、张数/秒数、输入素材、定价快照、折扣、金额和请求时长
- 支持模型级折扣与优惠前后价格展示；MiniMax H3 支持按输出秒数和输入图片/视频分别计费
- 成本看板支持项目过滤、汇总与分页流水；团队模式支持余额预检和完成后扣费
- 创作助手流水按会话汇总，展开后查看原始调用明细、失败状态与费用；保留原始用量记录，不重复计费
- 助手每轮可查看输入、输出、缓存及摘要用量；缓存价格使用当前供应商配置，未配置时明确提示

## 创作助手 Agent

### 用对话完成设定与分镜创作

- **查询、创建、修改与删除**：管理人物、场景、道具、衍生形态和分镜；按当前指定对象、章节或项目范围执行，服务端校验权限与版本
- **统一提示词规范**：复用系统的图片和分镜规范；局部修改支持精确片段替换，保留未修改的动作、声音和引用；独立分镜内的小镜头编号从 1 开始
- **长期与短期记忆**：保留近期对话；从用户原文中保存明确的持续要求，并按项目、章节、指定对象或剧情区间应用；新会话可继续使用相关规则
- **有界上下文**：按需查询对象、分页读取正文，对较早对话和已完成工具内容自动整理；原始记录保留，可检索操作依据；摘要失败时使用有界检查点继续任务
- **真实保存回执**：展示修改差异与撤销入口；重复请求不会重复写入，后续人工修改与版本冲突会阻止覆盖

助手统一编排创作设定、分镜、图片、视频与合成任务。工作区原有按钮继续保留，并与聊天使用相同的技能和执行边界；明确的生成请求会调用模型；含糊或候选操作需在界面核对确认，仅编辑提示词不会自动生成。

### 启用与使用

1. 在「设置 → 模型配置」中添加或编辑 LLM，勾选 **创作助手** 用途，并开启 **支持多轮工具调用**。
2. 在「设置 → 通用配置 → 创作助手」中启用助手并保存。开启鉴权时，全局助手配置由超级管理员管理。
3. 打开项目的设定页、故事版或工作流，点击右上角「创作助手」。也可以点击对象上的「用助手修改」，直接引用当前对象。
4. 选择修改范围并用自然语言描述要求，例如「只把这个分镜改成暖光，保留动作和声音」或「在当前章节新增一个雨夜车站场景」。
5. 通过回复下方的操作记录检查修改；需要时展开差异或撤销。顶部支持新会话、历史会话切换、删除及恢复会话。

桌面端助手与页面并排布局，打开时为侧栏让出空间。消息、查询结果、修改详情、记忆、用量和对象引用均支持折叠；模型选择位于输入区底部。折叠和运行状态动效参考 Beautiful UI，并保留[来源与许可](../web/src/features/creation-agent/beautiful-ui.NOTICE.md)。

## 首页的独立片段创作

首页用于一次一段的视频或图片创作。连续剧、多集剧本仍从「我的创作」进入原有流程。
输入后会收起首页推荐区，进入独立创作会话；最近片段可从首页继续打开。

- **直接使用提示词**：保留输入正文，提交所选真实模型的生成任务。上传的参考素材以既有引用协议绑定，不替换正文。
- **帮我设计镜头**：使用现有 Agent 和图片/分镜技能完善提示词，支持继续对话；生成操作在确认后执行。
- **先做参考图**：先完善镜头和参考画面提示词并生成参考图，确认画面后再生成视频。

可用模型、比例、清晰度和时长来自后台能力接口。无可用模型、连接失败、排队及生成失败均显示实际状态，
不使用样本媒体冒充生成结果。首页作品区只读取已公开作品和其已发布版本；未公开的项目不进入作品区。
片段的初次提交有幂等标识，刷新或重复请求不会重复创建同一首次任务。现有团队权限与用量记录沿用原链路。

项目封面的提示词和生图参数均跟随项目画面比例；历史未设置比例的项目保留原有 2:3 默认值。
当前生图模型不支持项目比例时报告失败，不静默换成竖版。项目列表及分析页保留完整封面，不拉伸或强制裁切。

首页参考素材支持与画布相同的 `@` 选择、键盘选择和引用标签删除。上传后可输入 `@` 或点击缩略图插入引用；仅上传但未引用的素材不会自动加入新请求的生成画面。移除素材会同步移除它的引用标记，其余正文保留。历史请求继续按原有绑定方式执行。

片段首次启动遇到余额或个人消费限额不足时，工作区、输入和参数保持可见，提供对应账户入口及处理后的继续按钮；它不改变余额校验、个人限额或实际扣费规则。首页装饰动图持续循环，不再提供手动暂停按钮。

首页生成按钮旁展示后台报价及当前可用余额。预计金额使用现有结算函数，包含所选图片/视频档位、时长、折扣、已引用素材及“先做参考图”的参考图费用；助手用量另行明确提示，按实际用量结算。可用额度同时受团队余额和个人剩余消费限额约束。余额低于预计金额、价格未配置或报价尚未完成时禁用按钮；等额且未触发现有欠费/限额限制时可提交。
报价接口只读，不创建任务、不冻结或扣减余额。新建片段及首次启动时服务端重新核验，已受理请求的幂等重放不重复扣减或生成。该检查不是资金预占，并发任务和最终实际用量仍按既有结算规则处理。


## 退出、停止与删除时的费用

关闭或退出创作页面只会停止页面刷新，后台已经启动的任务仍会继续。

删除项目会先停止排队任务及未提交的后续步骤。例如，分析尚未发出时删除不会再提交分析；分析请求已经发出时，保留本次实际用量，但停止尚未提交的封面生成。封面已经提交给模型服务时，仍须按实际返回结果和用量处理费用，删除不会自动退款。

存在执行中的模型请求、待结算用量或结果待核对的外部提交时，系统会先保留项目并提示暂时不能删除；收尾或人工核对完成后再次删除。项目删除后，已入账用量、团队扣费和费用流水保留在成本记录中，不因删除退回余额。
