# 模型配置与首次运行

[返回首页](../README.md) · [English](model-configuration.en.md)

## 首次运行检查表

1. 打开设置，填写文本模型的 API 地址、Key、模型 ID 与价格，并启用该配置。
2. 勾选「创作助手」用途并开启「支持多轮工具调用」，再到通用设置启用助手。开启鉴权时，全局助手开关由超级管理员管理。
3. 分别配置要用的图片、视频服务。模型调用权限和供应商费用由对应服务提供。
4. 导入一章短文本，检查资产提取与分镜，再决定是否付费生成媒体。

默认模型条目不包含可用 Key 或免费额度。助手是新创作任务的前置条件，只有图片/视频 Key 并不够；只配置文本模型时，也可以先进行故事分析、资产与分镜规划。

## 模型类型

AI 模型配置保存在数据库中，通过 Web 界面的「**设置 / 模型配置**」页（`/settings`）进行增删改、定价、折扣与启停，无需把供应商密钥写入源码。按任务类型配置，以下三类生成模型分别配置，画质增强另配：

### LLM 大模型（实体提取 / 分镜 / 项目分析 / 重制拆解 / 创作助手）

采用 **OpenAI 兼容协议**，可接入 OpenAI、DeepSeek、豆包、月之暗面等。一个模型可同时勾选多个“能力用途”；只有支持视频输入的多模态模型才应勾选“重制”：

| 字段 | 说明 |
|------|------|
| 名称 | 配置显示名，如 `deepseek-v3` |
| API 地址 | 供应商 base_url，如 `https://api.deepseek.com/v1` |
| API Key | 你的密钥 |
| 模型名称 | 如 `deepseek-chat` |
| 接口协议 | `openai_compatible` |
| 支持 JSON 输出 | 分镜等结构化任务建议开启 |
| 能力用途 | 可多选内容理解、分镜规划、项目分析、重制、创作助手；“重制”要求模型支持视频输入 |
| 支持多轮工具调用 | 创作助手必需；仅开启支持 JSON 输出不能替代工具调用能力 |
| 上下文字符上限 / 最大输出 token | 模型级限制，与助手全局设置共同生效，填写供应商或代理实际支持的值 |
| 思考模式 | 可按模型配置开启或关闭；豆包关闭时使用方舟兼容的 `thinking=disabled` |
| 并发与超时 | 重制镜头并发读取模型配置；单次视频理解请求最长等待 10 分钟 |

### 图像模型（参考图生成）

| 模型类型 | 说明 | 协议 |
|------|------|------|
| Doubao Seedream 5.0 Lite / Pro / Flash | 豆包生图 | `volcengine_ark` / `openrouter_compatible` |
| GPT Image 2 | OpenAI 生图 | `openai_compatible` / `openrouter_compatible` |

### 视频模型（视频合成）

视频请求统一进入模型工厂，再由所选配置的 `video_model_type` 选择适配器并校验素材、时长、比例、分辨率与接口协议。

| 模型类型 | 主要能力 | 协议 |
|------|------|------|
| Doubao Seedance 2.0 / Fast / Mini | 参考图/视频/音频、首尾帧、同步声音，最长 15 秒 | `volcengine_ark` |
| Doubao Seedance 2.5 | 更多参考素材、最长 30 秒、系统音频素材 `asset://` | `volcengine_ark` |
| MiniMax H3 | 768P / 2K、参考图/视频/音频、首尾帧 | `minimax` |
| Wan3 | 文生/图生/首尾帧/全能参考，支持百炼临时素材上传 | `dashscope` |

> 每种任务类型可同时启用多个配置。前端只展示当前模型实际支持的参数；供应商不返回尾帧时由 FFmpeg 兜底，不需要在适配器中伪造能力。

## 助手上下文与用量设置

以下是项目当前采用的 DeepSeek 长上下文预设，均可在「高级设置」调整；调用次数、对象数、超时和每轮总用量是本项目的运行策略，并非供应商的统一默认值。

| 设置 | 默认值 |
|------|--------|
| 工作上下文预算 | 840,000 预估输入 token |
| 上下文字符硬上限 | 2,000,000 字符 |
| 整理触发 / 目标比例 | 70% / 45% |
| 单次输出 / 每轮累计用量上限 | 64,000 / 2,000,000 token |
| 每轮模型 / 工具调用上限 | 20 / 50 次 |
| 每轮对象数 / 运行超时 | 32 个 / 600 秒 |
| 历史处理轮数参数 / 每页正文读取 | 12 轮 / 4,000 字符 |
| 摘要输出 / 等待上限 | 4,000 token / 30 秒 |

这些数值是上限，不会预先填满上下文。模型配置中更低的输出和上下文字符限制仍会生效；切换模型或代理时应按其实际能力调整。每轮累计用量包含多次调用，与单次上下文窗口不同，压缩不会退还已经消耗的用量。

完整匹配旧版默认限制的已保存配置会在读取时应用新预设；任何限制已有自定义值时保留整套配置。原始聊天记录不因压缩而删除，缓存命中与费用以供应商实际返回的用量及后台配置价格为准。

## 常见问题

| 现象 | 优先检查 |
| --- | --- |
| 提示未配置创作助手 | 文本模型启用状态、助手用途、工具调用能力，以及通用设置中的助手开关 |
| 图片/视频模型不可选 | 任务类型、协议、模型能力类型、启用状态和当前团队的模型来源 |
| 供应商鉴权或 IP 限制 | API 地址、Key 权限与供应商白名单；不要把 Key 发到 Issue 中 |
| 长请求或结构化内容截断 | 当前模型/代理实际支持的上下文和输出上限、助手预算、供应商错误码 |
| 视频探测/合并/重制/高清化失败 | 后端运行环境是否有 FFmpeg、ffprobe，以及文件是否可访问 |
| 清晰度选项不可用 | 增强服务是否启用了该档位并配置价格，目标是否高于文件真实清晰度 |

当前后端 Dockerfile 未预装 FFmpeg。运行 `docker compose exec -u root backend sh -c 'apt-get update && apt-get install -y --no-install-recommends ffmpeg && rm -rf /var/lib/apt/lists/*'` 后，用 `docker compose exec backend ffprobe -version` 验证；重建镜像后需重新安装。本地开发则要求后端主机的 PATH 能找到 FFmpeg。

已保存的完整提示词默认原样使用。调整风格或 Skills 后，如需改变旧资产效果，应先优化并保存提示词，再生成，详见[技能定制](agent-skills-workflow.md)。

MediaKit 属于独立的「视频画质增强」配置，不是生视频模型，详见[画质增强](video-enhancement.md)。
