# 章节视频编辑工作台

[English](video-editor.en.md)

实施分支：`codex/video-editor`。目标为已确认的左侧素材、中间预览、右侧属性、底部多轨时间线设计。

## 数据与权限方案（需人工审核）

新增 `chapter_edit_drafts`（章节唯一、修订号、类型化草稿）与 `editor_assets`（项目素材、实际媒体探测与校验值）两张表，通过安全建表补齐；不删除或覆盖原表、分镜、历史媒体、声音种子或账务数据。回滚代码可保留新表，不需删表。先用隔离数据库验收初始化、重复启动与旧数据兼容，本地现有库如需迁移先备份。

读取与编辑使用现有项目／团队权限；查看者只能读取。素材上传沿用现有媒体存储与访问方式，提交的素材 ID 必须重新校验项目或团队归属。剪辑草稿只保存 ID，不接受客户端传入路径、远程链接、命令或 FFmpeg 过滤器。上传类型、大小、实际格式和时长均在服务端校验。从时间线移除仅修改草稿，不删除素材。

导出复用 `ChapterExport` 与 `AiTask` 作为持久化状态，冻结草稿修订与已核对的内部媒体。新增本地渲染执行器只处理 `editor_render`，采用单并发、数据库租约、临时文件与取消检查，不调用模型、不写模型消费流水；不调整原有鉴权或扣费逻辑。相同内容复用结果，明确失败后的重试只重复本地渲染。输出保留在既有私有导出目录，下载沿用已有权限通道。

## 实施与验收

1. 版本化草稿、导入素材、权限、保存冲突与旧项目首次读取。
2. 固定数据模型下的镜头编排、裁剪、变速、音量、字幕、静态贴纸、撤销重做和自动保存。
3. 浏览器统一时钟预览、缓冲切换与多轨音频同步。
4. 有界 FFmpeg 导出、结果校验、幂等、取消和恢复，以及实际媒体效果验证。

原始镜头 ZIP 与编辑成片分开；ZIP 继续从现有镜头媒体在浏览器打包。生成新镜头或高清版本不会静默替换已保存草稿中的媒体，需要用户显式替换。缺失来源会阻止导出并标明对应片段。

不新增自动语音识别、AI 贴纸或收费模型能力；字幕首期支持手动编辑与 SRT，贴纸支持用户上传 PNG/WebP。


## 使用与部署

- 「画布尺寸」只设置导出尺寸，使用普通缩放与补边，不执行 AI 画质增强。需要 AI 增强时仍使用分镜或画布的高清化入口。
- 顶部「素材 ZIP」下载原分镜当前视频，编号顺序不变，不经过本地渲染器；「导出成片」按保存的剪辑草稿生成新文件，两者分开。
- 左侧导入视频、MP3/WAV/M4A 音乐、PNG/WebP 静态贴纸；支持从团队视频资源库选择视频。浏览素材仅预览，点击加号才加入时间线。音乐与贴纸可跨本项目章节复用。
- 字幕支持手动编辑及 SRT 导入。普通文本按画布宽度自动换行；不执行 HTML/ASS 或模型在线生成。首期使用系统中文黑体，字幕字号按 1080 高度的参考坐标缩放。
- 时间线支持选中、拖动、键盘微移、边缘裁剪、数值裁剪、分割、复制与撤销／重做。视频主轨不允许重叠；需要重新排列时先移动到空位或用插入功能，其他轨道支持多个片段。
- 保存自动进行；网络错误可重试，409 冲突保留本地草稿并停止覆盖，刷新可选择恢复本地修改。草稿按用户、团队、项目和章节隔离。导出前必须保存成功。
- 成片导出在后台执行，可关闭弹窗；结果和进度保留在导出记录中。重新启动后通过租约恢复本地任务。重复点击复用同一内容的导出记录，失败后的重试仅重新渲染本地文件。
- 系统需具备 FFmpeg（libx264、AAC、drawtext、overlay、amix）与 Fontconfig 及中文字体。两个后端 Docker 镜像已加入 `ffmpeg fontconfig fonts-noto-cjk`；手动部署需自行安装系统包，缺失时会显示渲染失败而不会伪装成功。Python/npm 依赖和锁文件未变动。
- 临时文件位于 `CHAPTER_EXPORT_PATH` 所在持久磁盘，渲染每次只规范一个镜头，叠加图片每批最多 4 张。通过 `VIDEO_EDITOR_MAX_DURATION_SECONDS`、`VIDEO_EDITOR_MAX_OVERLAYS`、`VIDEO_EDITOR_MAX_AUDIO_TRACKS`、`VIDEO_EDITOR_MAX_SOURCE_MB`、`VIDEO_EDITOR_RENDER_TIMEOUT` 配置时长、片段和资源限制，接口会返回当前限制。不会把大量源视频放入内存或 `/tmp` 的内存盘。

## 实际验收记录

- 已使用两个隔离章节和真实可解码的短视频，在浏览器验证读取、字幕编辑、自动保存、刷新恢复、章节隔离、音乐与图片贴纸上传、额外视频插入及变速。
- 第一章通过浏览器导出并下载：1280×720、24fps、6 秒、H.264/AAC、48kHz 双声道；抽帧检查了中英字幕和图片贴纸，完整解码无错误。真实测试修复了多个 AAC 片段拼接的时间戳冲突，当前镜头先以 PCM 音频规范，再统一编码连续音轨。
- PostgreSQL 14.19 的隔离实例通过旧表数据保留、新表创建、重复初始化、并发保存的 409 冲突以及空时间线拒绝导出；SQLite 回归也覆盖相同行为。没有操作生产数据库或发起真实模型付费调用。
- 第二章实测导入额外视频、1.5× 变速与中英 SRT，按 480×854、30fps 导出 8 秒竖屏成片；浏览素材不会插入时间线，显式点击加号才插入。
- 前端全量 787 项、类型检查与生产构建通过；后端全量 1492 项通过，权限专项 38 项通过。深浅主题和窄屏均已核对，预览容器不额外添加留白，视频按原比例适应可用区域。

尚未验收生产服务器的长片吞吐、海量素材与真实 OSS 上传／导出，本地文件和权限已实测，OSS 复用现有 Provider。移动端保留可用的预览和抽屉式编辑，但以桌面剪辑为主要工作方式。当前不提供转场、关键帧、自动字幕识别、动态贴纸或多视频画中画，这些不属于本期确认范围。
