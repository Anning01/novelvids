# 无线画布与 Shengshi Media 对齐设计

日期：2026-07-25

状态：已批准

参考页面：`https://meida.sscmsc.com/create/viral-workbench/cw_eafa9fab72bb4f41831f1737543abddd`

本地页面：`/dashboard#/create/short-drama/storyboard/:novelId?chapter=:chapterId&view=workflow`

## 1. 背景与目标

当前无线画布已经具备 Vue Flow 画布、章节/资产/镜头/视频结果节点、便签、分区、资源引用节点和基础工具栏，但它与 Shengshi Media 的参考实现仍有明显的交互、布局和功能差异。逐按钮核验还发现了一组会放大所有表层差异的底层缺陷：

- `CreativeCanvas.vue` 为 `<VueFlow>` 指定了 `id="novel-workbench"`，但脚本调用无参数的 `useVueFlow()`。在当前 `@vue-flow/core@1.48.2` 中，这可能创建另一个未初始化实例，导致 `fitView`、`getViewport`、`setViewport`、`getNodes` 和屏幕坐标换算不作用于可见画布。
- 节点的 Vue Flow 选中状态与 Pinia `selectedNodeKeys` 没有稳定同步，因而“删除、复制、分区、运行所选配置”等依赖业务选择态的按钮会错误禁用。
- 自动布局在镜头较多时形成过高的单列，`fitView` 后节点过小；新增镜头还可能出现在当前可视区域之外。
- `ShotNode.vue` 使用多个根节点并接收未声明监听器，浏览器控制台持续出现 Vue fragment 警告。
- 当前新增菜单、工具栏、资产节点、镜头节点、上传媒体、批注、水印和视频合成能力均未达到参考页面的交互深度。

本设计采用“根因优先、逐层对齐”的方案。最终目标是在不破坏现有短剧工作流和故事板视图的前提下，使无线画布在视觉层级、按钮状态、操作反馈、布局稳定性与核心节点能力上与参考页面一致，并为每个可见按钮建立可重复的浏览器回归验证。

## 2. 设计原则

1. **同一状态只保留一个权威来源。** Vue Flow 负责几何交互，Pinia 负责可持久化业务状态；二者通过显式适配器同步，不靠监听时序猜测。
2. **先修基础设施，再补功能。** 选择、视口、坐标、布局和历史记录不稳定时，不开始堆叠复杂节点。
3. **真实能力、真实反馈。** 未接通的上传、生成、合成能力必须显示不可用原因，不允许展示虚假的成功结果。
4. **每次操作可观察、可恢复。** 普通编辑可撤销；后端操作失败时本地画布不残留半完成数据；临时测试数据必须清理。
5. **参考行为优先，保留产品特有能力。** 参考页面已有的入口按相同分组呈现；本项目独有的参考音频、数字人和“故事板/工作流”切换保留，但不混入参考菜单主序列。

### 3.1 本次包含

- 画布实例、选择同步、视口持久化、屏幕坐标换算和自动布局。
- 顶部画布信息区、工具栏、提示文本、按钮尺寸和禁用态。

- 上传图片批注、水印配置、视频合成排序与输出配置。
- 撤销/重做、复制/粘贴、删除、锁定、忽略、折叠、置顶和分区。

- 重做短剧故事板视图或其他非画布页面。

- 复刻参考页面自身可复现的明显缺陷；例如节点内删除按钮失效时，本地实现仍应正确删除。
- 未经用户动作自动触发付费生成、合成或外部上传。

| 资产节点 | 类型、昵称、数字人、生成数、尺寸、格式、候选图、主图版本 | 仅描述编辑与生成 | 补齐配置与版本态，复用真实资产 API |
| 镜头节点 | 时长滑杆、比例、分辨率、尾帧、资产引用策略、视频版本 | 描述、提示词、时长输入、模型 | 补齐配置，选择时打开提示词编辑器，版本切换稳定 |
| 上传图片 | 节点预览与批注工具 | 无 | 新增持久化媒体节点和批注弹层 |
| 水印 | 资源选择、预设位置、X/Y/缩放 | 无 | 新增水印节点、配置弹层和输出连接 |
| 视频合成 | 镜头视频排序、上移/下移、分辨率、比例、合成 | 无 | 新增合成节点及真实执行边界 |

## 5. 总体架构

### 5.1 具名 Vue Flow 实例

定义唯一常量：

```ts
export const WORKBENCH_FLOW_ID = 'novel-workbench'
```

模板 `<VueFlow :id="WORKBENCH_FLOW_ID">` 和脚本 `useVueFlow(WORKBENCH_FLOW_ID)` 必须使用同一常量。任何依赖实例的方法只能从这个具名实例取得，包括：

- `fitView`
- `getViewport` / `setViewport`
- `getNodes`
- `screenToFlowCoordinate`
- `panBy`
- `vueFlowRef`

画布未完成初始化前不执行适配视图或坐标换算。首次渲染、路由切换和节点批量重建使用明确的 `nodesInitialized`/下一帧边界，不用固定延时规避竞态。

### 5.2 选择状态适配器

引入一个集中式选择适配器，负责 Vue Flow 与 Pinia 的双向同步：

```text
用户点击/框选/快捷键
        ↓
Vue Flow selection change
        ↓
标准化节点 key 和边 key
        ↓
Pinia selectedNodeKeys / selectedEdgeKeys
        ↓
工具栏、节点面板、运行按钮派生状态
```

规则如下：

- 普通点击只选中一个节点；组合键和框选遵循 Vue Flow 原生多选。
- 点击空白区域清空节点和边选择。
- Store 主动选择新建节点、粘贴节点或跳转节点时，将选择态回写到 Vue Flow。
- 同值同步不重复写入，避免循环事件。
- 节点删除或图重建后清除无效 key。
- 工具栏不得读取 Vue Flow DOM 类名判断选择；节点组件不得通过“先选中再删除”的竞态删除自身，而应把自身 key 传给显式删除动作。

### 5.3 视口与新增位置

视口以 `chapterId` 为隔离键持久化，保存 `{x, y, zoom}` 和保存时画布尺寸。恢复时对缩放范围做校验，并在容器尺寸发生明显变化时保持视口中心点，不直接照搬旧像素偏移。

新增节点位置通过真实实例的 `screenToFlowCoordinate()` 计算：

- 菜单新增：落在当前视口中心略偏右下。
- 上下文新增：落在用户触发位置。
- 粘贴：相对源节点偏移，并在连续粘贴时递增。
- 后端创建成功后才插入自动节点；插入后立即选中并以最小必要幅度移入视野。

不再手工使用未初始化 viewport 反推坐标。

### 5.4 有界多列自动布局

自动布局继续复用 `workbenchAutoLayout.ts` 的“按家族分层”思想，但增加有界分栏：

- 左侧：章节与来源。
- 中左：资产、上传媒体、本地专属参考资源。
- 中部：镜头；按可用画布高度计算每列最大节点数，超过上限后向右换列。
- 中右：镜头输出、加水印输出。
- 右侧：视频合成。
- 便签在主流程之外保留相对位置。
- 分区作为原子布局单元，成员保持组内相对位置。
- 已置顶/锁定或标记为手动固定的节点不被自动布局移动。

布局输入使用已测量尺寸；没有尺寸时使用各节点类型的稳定默认尺寸。布局完成后等待几何更新，再对正确实例执行一次带边距的 `fitView`。目标是在 15 个镜头的已核验数据上仍保持可读卡片宽度，不出现高度数千像素的单列。

### 5.5 历史与剪贴板

历史快照覆盖：

- 节点位置、尺寸、层级和折叠/忽略/锁定等 UI 状态；
- 全部手动节点及其配置；
- 手动连接和排序；
- 视口；
- 分区成员关系。

新增、删除、移动结束、调整尺寸结束、配置提交、连接、断开、排序和批量布局在变更前建立检查点。连续拖动和滑杆输入在交互结束时合并为一个历史步骤。

后端创建/删除与普通本地历史分开处理：

- API 成功前不提交最终本地状态。
- API 失败时恢复变更前快照并展示可理解错误。
- 无法可靠补偿的后端删除不标为可撤销，界面需明确说明。
- 复制镜头调用后端创建时，失败不得遗留临时节点；成功后才更新剪贴板落点与选择态。

### 5.6 节点数据模型

扩展 `WorkbenchNodeKind`：

```ts
type WorkbenchNodeKind =
  | 'chapter'
  | 'asset'
  | 'audio_reference'
  | 'digital_human'
  | 'shot'
  | 'video_result'
  | 'image_media'
  | 'video_media'
  | 'audio_media'
  | 'watermark'
  | 'video_composer'
  | 'section'
  | 'note'
  | 'unsupported'
```

手动节点数据使用可判别的配置类型，不再依赖任意字符串字典。至少包含：

- 媒体：资源标识、URL、名称、MIME、尺寸/时长、上传状态和批注数据。
- 水印：资源来源、五个预设位置、归一化 X/Y、缩放和目标视频连接。
- 合成：有序视频项、输出比例、分辨率、执行状态和结果引用。
- 资产 UI 配置：资产类型、昵称、生成数、尺寸、格式、候选版本和主版本。
- 镜头 UI 配置：时长、比例、分辨率、尾帧、资产注入策略、所用版本和当前视频版本。

短期仍用带版本号的章节级持久化存储保存纯 UI/手动节点状态，但读写集中到一个序列化层，支持旧 `layout:v1` 数据迁移。服务端已有实体继续以 API 数据为权威，不能被本地旧缓存覆盖。

## 6. 界面与交互设计

### 6.1 顶部区域

- 左侧保留返回入口，返回本项目的项目列表。
- 增加可展开的画布身份区，显示并可编辑当前画布/章节名称。
- 保留“故事板 / 工作流”切换，放在画布身份区之后，不挤占操作按钮。
- 工具按钮统一为约 34px 高，图标、圆角、间距、悬停和禁用对比度参照参考页面。
- Tooltip 同时说明动作和快捷键，例如“撤销 ⌘Z”“删除 Delete/Backspace”“适配视图”。
- 主按钮默认文案为“请先选择可执行节点”并禁用；选择一个或多个可运行节点后变为“运行所选配置”。
- 运行前对所有选择节点进行能力校验。若需要额度、上传资源或缺少必填项，按钮禁用并在 Tooltip 中给出具体原因。

### 6.2 工具栏按钮状态

| 操作 | 启用条件 | 执行结果 |
| --- | --- | --- |
| 选择/平移 | 始终 | 切换互斥模式并更新 `aria-pressed` |
| 放大/缩小 | 画布已初始化且未到缩放边界 | 只改变当前具名画布 |
| 适配视图 | 至少一个可见节点 | 将全部非隐藏节点纳入可读视口 |
| 锁定 | 始终 | 禁止拖动、连接和尺寸调整，但保留选择与查看 |
| 自动布局 | 至少两个可布局单元 | 建立检查点，布局并适配视图 |
| 撤销/重做 | 相应历史栈非空 | 恢复图和视口，保持有效选择 |
| 复制 | 恰有一个可复制节点 | 更新画布剪贴板 |
| 粘贴 | 剪贴板有效且权限允许 | 在可视区域创建并选中新节点 |
| 删除 | 选择中至少一个可删除对象 | 按对象类别执行本地或后端删除 |
| 创建分区 | 至少选择两个可分组节点 | 创建背景分区并保留成员位置 |

键盘快捷键在输入框、文本域、内容编辑器和滑杆聚焦时不得误触。

### 6.3 新增菜单

菜单主组按参考页面顺序提供：

1. 空资产
2. 镜头
3. 便签
4. 水印
5. 视频合成
6. 上传图片
7. 上传视频
8. 上传音频

第二组“项目资源”保留：

- 参考音频
- 数字人

上传入口使用隐藏文件输入与明确的 MIME/大小校验。用户取消文件选择不创建空节点；上传失败不留下不可用节点；上传成功后节点进入当前视口并立即选中。

### 6.4 通用节点框架

`WorkbenchNodeFrame.vue` 统一提供选中态工具条：

- 节点信息；
- 颜色；
- 置顶；
- 折叠；
- 忽略；
- 删除。

每个动作都直接接收当前节点 key。节点可删除性由能力表配置，不再散落在组件条件中。折叠后仍保留标题、状态、关键缩略图和连接端口。忽略态不参与运行，但仍可布局、查看和恢复。

`ShotNode.vue` 改为单根布局，提示词编辑器通过框架内部插槽或 Teleport 呈现，显式声明/透传 Vue Flow 所需属性和事件，从而消除 fragment 与 `updateNodeInternals` 警告。

### 6.5 资产节点

资产节点对齐以下字段和动作：

- 类型：人物、物品、场景、商品、风格；
- 昵称；
- 人物资产的数字人选择；
- 生成数量；
- 尺寸预设，包括 1K/2K；
- 输出格式，当前后端仅支持时只展示 PNG；
- 候选图片列表；
- 主图版本选择；
- 编辑提示词；
- 生成。

选择主版本只更新真实资产版本关系。生成按钮走现有资产生成 API，显示执行中、成功或失败状态；无权限、缺输入或正在执行时必须禁用。

### 6.6 镜头节点

镜头节点包含：

- 镜头说明；
- 视频提示词；
- 时长滑杆与数值；
- 画面比例：16:9、9:16、1:1、4:3、3:4；
- 分辨率：480p、720p、1080p；
- 尾帧开关；
- 可折叠的资产引用；
- 使用方式：提示词注入、参考图片；
- 视频模型；
- 已生成视频版本和当前版本；
- 保存；
- 保存并生成；
- 运行此配置。

字段选择必须经过模型能力映射。后端或模型不支持的组合显示禁用原因，不静默丢弃。选中镜头时打开提示词编辑区；关闭编辑区不清除节点选择。

### 6.7 上传媒体与图片批注

图片、视频、音频节点共享上传状态和资源信息。图片节点提供批注弹层：

- 移动；
- 矩形；
- 椭圆；
- 网格；
- 箭头；
- 涂鸦；
- 画笔粗细；
- 放大、缩小、重置；
- 撤销；
- 清空；
- 保存。

批注使用归一化坐标保存，确保节点预览尺寸变化后仍能正确重绘。关闭未保存批注时提示丢弃；保存失败保留编辑内容并允许重试。

### 6.8 水印节点

水印节点提供：

- 水印资源选择或上传；
- 五个预设位置：左上角、右上角、左下角、右下角、居中；
- X/Y 精细调整；
- 缩放；
- 输入视频连接；
- 水印输出连接。

位置使用 0–1 归一化坐标，预设位置只是对 X/Y 的快捷赋值。后端水印执行通过明确的媒体执行适配器调用；尚未具备执行能力的环境允许完成配置和连线，但运行按钮必须禁用并说明“当前服务未启用水印执行”，不能生成假结果。

### 6.9 视频合成节点

合成节点接收多个视频结果或水印输出，提供：

- 有序片段列表；
- 上移、下移；
- 输出分辨率；
- 输出比例；
- 预计时长；
- 合成/预览；
- 执行状态与输出结果。

排序写入显式 `orderIndex`，不能依赖连线创建时间。运行前校验至少一个有效片段、资源可访问和参数受后端支持。合成属于潜在计费/耗时操作，只有用户明确点击后才提交；重复点击在任务进行中被禁止。

## 7. API 与执行边界

组件不直接拼装 API 请求。Store 调用类型化的 workbench API adapter：

- `createShot` / `updateShot` / `deleteShot`
- `generateAsset`
- `generateShotVideo`
- `uploadMedia`
- `applyWatermark`
- `composeVideo`
- `pollTask`

adapter 将节点配置映射为现有 API schema，并返回统一的任务状态。已有后端路由直接复用；缺少的水印、合成执行能力通过独立接口扩展，前端用能力响应决定是否启用按钮。错误需区分参数错误、权限/额度、网络、服务未启用和任务失败。

任何潜在计费操作都必须由用户明确点击触发。浏览器自动回归只验证禁用态、确认层和请求前状态，除非另行获得执行真实生成的授权。

## 8. 错误与并发处理

- 加载新章节时取消或忽略旧章节的迟到响应。
- 同一资产或镜头执行期间禁用重复运行，但不阻塞其他独立节点。
- API 失败保留用户输入，恢复图结构，显示可重试提示。
- 上传失败允许重新选择文件；取消上传清理临时 object URL。
- 轮询停止条件包括成功、失败、取消、超时和离开页面。
- 本地持久化解析失败时回退到默认布局并记录可诊断警告，不阻止页面使用。
- 控制台验收要求无线画布流程无 Vue warning、未处理 Promise rejection 和 Vue Flow “Viewport not initialized”错误。

## 10. 分阶段实施

1. **基础稳定层**：具名实例、选择适配器、视口、坐标、单根镜头节点和控制台清零。
2. **布局与编辑层**：有界布局、历史、剪贴板、分区、删除和工具栏状态。

4. **节点能力层**：资产、镜头、媒体批注、水印、视频合成和执行适配器。

- 本地页面不再出现 `Viewport not initialized yet`、fragment listener 或未处理异步错误。

## 12. 实施影响

本设计会把当前散落在 `CreativeCanvas.vue`、节点组件和 Store 中的交互逻辑收敛到具名画布适配器、选择适配器、序列化层和执行 adapter。这样新增节点类型不再重复处理选择、视口、历史和失败恢复，也能让后续与参考页面的差异变成局部组件问题，而不是全局画布状态问题。
