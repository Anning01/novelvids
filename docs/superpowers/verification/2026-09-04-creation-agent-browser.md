## 本轮发现与处理

1. 窄屏面板只有 aside，缺少模态语义。增加响应式 dialog/aria-modal，并在收窄时把外部焦点移入面板。沿用原有键盘循环和共享壳的焦点归还，没有新建对话框组件库。
2. 第一轮旧对话运行失败，页面显示“运行未完成”，没有假报保存。检查发现隔离服务仍运行此前加载的代码，且 FunctionModel 仅支持流式响应，未提供历史摘要所需的普通响应；加载当前代码并补齐验收模型后复验成功。旧进程未保留完整异常栈，因此不把这次修复组合当作产品故障根因的单变量证明。此处修改在临时验收服务，不把它冒充产品逻辑缺陷或真实模型结果。
3. 临时前端进程在初次加载时已停止，确认端口无监听后才恢复服务。没有将旧句柄或页面壳当作服务仍正常的证据。
4. 最新浏览器补验发现保存后待核对标记没有清除。SQLite存储UTC时间，而生产配置读取为上海时区；跨表时间过滤直接比较带不同偏移的字符串，漏掉实际已完成记录。用生产时区设置补充失败回归后，移除不必要的时间过滤，按最新记录、当前Prompt及明确的约束ID判断；保留每批100条读取。定向24项通过，实际页面复验清除成功。
5. 异常终态恢复：原store只恢复active_task_id，已结束的失败会话重开时丢失当前运行状态；切换空会话可能残留上一轮成功文案，成功重连也可能残留连接错误。三项失败回归后，改为恢复当前会话最后一条助手消息的运行快照、清空跨会话状态，并由已结束快照更新错误。只读取快照，不重发模型请求。
6. 手选范围稳定性：第一轮部分失败验收发现，页面联动改变默认镜头会在输入时覆盖已手选范围，实际请求只含Scene3，因此不把该次当作双目标验收。修复后显式手选优先于同章默认目标变化，仅切换项目/章节重新初始化。补回归覆盖相同默认目标刷新及不同默认目标变化。

## 部分保存后失败及恢复

在独立临时服务中使用“离线部分失败验收”FunctionModel：首项工具事务成功后抛出合成异常，无外部请求。最终有效请求明确包含Scene2、Scene3，任务状态4；PromptChange9仅含Scene2，冷光改暖光，Scene3无该任务修改记录。页面显示“运行未完成，已保存的修改仍可查看”、错误提示和保存卡；展开差异明确显示“分镜 #2”及前后内容。

刷新后自动恢复对话2及上述失败状态，临时数据库任务数保持10，未重复执行。撤销记录9后页面显示“已撤销”，Scene2恢复冷光，任务仍显示未完成。证据与测试结果：`run-recovery-before.log`三项失败；`run-recovery-after.log`两文件19项通过；`run-recovery-build.log`类型及构建通过。此项只证明合成部分保存/失败/重载/撤销路径，不代替真实供应商故障、超时和取消完整矩阵。

## 停止与迟到响应

在独立临时服务中使用“离线停止验收”FunctionModel：第一次读取上下文，第二次模型请求停在明确的验收屏障，尚未返回写入工具。页面通过停止按钮的Enter键触发停止，立即显示“已停止”。随后人工释放合成响应屏障，确认模型确实返回迟到的工具调用。

返回后任务状态仍为5、该任务PromptChange为0，Scene2保持原冷光Prompt；两次已发生模型请求均有用量检查点。刷新恢复对话3后仍显示停止，未产生改动记录。该路径无供应商请求及媒体生成，不能据此宣称取消能追回供应商已消费费用。

## 流式旧消息阅读（2026-09-05）

使用临时FunctionModel先发送一段说明并等待屏障。对话1的消息列表高度961、内容高度1650；通过实际滚轮上翻到scrollTop=0，出现“回到最新”。随后释放8次流式增量，消息内容继续接收，列表内容估算高度增至1734，scrollTop仍为0，没有抢滚动。

任务最终状态3，数据库回复含最后一段“补充说明8”，该任务PromptChange为0。点击“回到最新”后，列表scrollTop=1774、clientHeight=961、scrollHeight=2735，页面能看到最后一段，精确到达底部。复用BubbleList原生滚动逻辑，没有添加独立滚动实现；同一条回复的增量不冒充多条新消息计数。该项证明持续增量不抢滚动及返回最新路径，不代表所有历史分页边界或性能压力场景均已覆盖。

完成后已停用隔离数据库中的部分失败、停止屏障和流式屏障三个临时模型，保留普通离线模型用于预览。

## 主要文字对比度抽查（2026-09-05）

读取实际渲染的计算样式，按sRGB相对亮度计算前景/背景对比；半透明用户气泡按祖先背景合成。采样范围为助手标题、模型/会话选择器、修改范围说明、约束提示、用户/助手消息、运行状态和输入正文（字号11–14px）。

| 文字范围 | 浅色 | 深色 |
| --- | --- | --- |
| 标题及输入正文 | 12.39:1 | 13.73:1 |
| 选择器、范围说明、运行状态 | 5.33:1 | 8.98:1 |
| 约束提示 | 5.33:1 | 4.64:1 |
| 助手/用户气泡 | 11.17:1 / 10.87:1 | 12.59:1 / 11.01:1 |

上述采样均达到普通正文4.5:1。输入占位文字当前为与正文相同的rgb(48,52,66)，opacity=1。抽查不等于完整WCAG认证，不覆盖所有悬停/焦点/禁用状态或图片内容。检查后已恢复原浅色主题。
