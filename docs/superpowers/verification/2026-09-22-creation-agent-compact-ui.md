# 创作助手紧凑布局

- 用户消息、助手回复可单独展开/收起，顶部支持全部消息折叠。用户消息默认显示单行预览，助手回复默认展开；查询、修改差异、用量、记忆和引用对象默认收起。折叠不修改消息或对象数据。
- 查询和操作回执采用统一的单行折叠栏。撤销入口保留在回执右侧，独立于详情展开。
- 合并底部运行状态、错误详情与约束提示；新错误自动展开，停止按钮持续可用。移除没有内容的等待气泡，运行状态仅显示一处真实反馈。
- 顶栏、会话栏、章节栏和输入区均缩小留白。正文按段落渲染，避免继承聊天组件的 pre-wrap 将模板空白渲染为额外行。
- Beautiful UI 的 ThinkingState 网格折叠、箭头旋转及 shimmer 动效已适配到 Vue。保留原有 BubbleList 和 XSender，不引入 React、不升级依赖。原始出处和 MIT 许可见 `web/src/features/creation-agent/beautiful-ui.NOTICE.md`。
- 所有折叠入口使用原生按钮、aria-expanded、aria-controls；收起内容不进入键盘焦点，展开保持内部组件状态。动效遵守 prefers-reduced-motion。

## 验证

- 助手相关测试 63 项；前端类型检查和生产构建。
- 真实页面验证浅色/深色、全部折叠、键盘展开、助手关闭重开、引用保留与横向溢出。测试后恢复跟随系统主题，没有发送模型请求或修改业务对象。
- 420px 助手侧栏实测：顶栏约 38px，单个引用下输入区约 114px，消息间隔 10px。全部收起时单条内容折叠栏为 26px，未出现横向溢出。
