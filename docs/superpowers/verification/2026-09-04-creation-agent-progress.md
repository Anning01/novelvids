## 实现范围与复用

- 后端使用 Pydantic AI 的真实工具循环及官方 AGUIAdapter，前端使用官方 HttpAgent、Element Plus X 的 BubbleList/XSender。没有自行实现 Agent 循环、SSE 解析或聊天基础库。
- 两个业务写工具仅修改 Asset/AssetVariant 的图片 Prompt，以及 Scene 的分镜 Prompt/对应视觉结构。一个只读工具加载授权目标及上下文；结构化回复中的创作记忆不提供任意数据库写入能力。没有媒体生成、章节删除、任意文件或代码执行工具。
- 延用 `api → controllers → services/models` 分层、现有 AiTask 执行器、模型配置解析、账单记录和余额路径。会话/消息、约束与 PromptChange 使用必要的新表；不新建平行任务和计费系统。
- 复用 `prompts/storyboard.py` 渲染器及已有素材形态选择规则。内部小镜头由程序从 1 编号，时长总和受校验；角色定义随独立请求展开。兼容旧纯文本并保留既有台词、旁白、声音和非视觉参数。
- 会话历史按所有者隔离；共享创作约束保存来源、作用范围及替代关系。每轮加载当前事实，摘要增量生成并保留源消息。作用范围在每个目标上分别计算，写入前检查约束版本。
- 提交时冻结目标范围；工具写入有版本前提、幂等标识和批次事务。重复请求、断流重连、取消与启动恢复通过已有任务状态协调，不重放已完成模型操作。撤销遇到后续修改会拒绝覆盖。
- 共享工作台壳承载同一助手面板和 Pinia store，包含目标选择、真实保存记录、差异、定位、撤销、停止及重连。设定/分镜/画布刷新保留未保存草稿；手工保存带原 Prompt 前提，过期草稿返回冲突。
- 新约束待核对提示：复用既有PromptChange，在工具事务内记录本次各目标实际读到的约束ID；新增有项目权限和100目标上限的只读状态查询。对象列表展示尚未用于当前Prompt的规则，保存/撤销/运行结束、打开列表或窗口重新聚焦时刷新。查询不修改Prompt、不自动扩大选中范围。撤销、后续手工改动、规则替换或旧记录缺少约束快照时保持待核对；不把清除提示视为语义质量合格。
- 最新定位修复：变体改动记录携带所属资产 ID，定位到正确资产抽屉并选中具体变体；不把变体编号当作资产编号。旧缺少所属信息的记录明确提示，不猜测对象。
