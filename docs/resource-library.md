# 团队共享视频资源库

## 使用

侧边栏「资源库」提供团队共享视频，跨项目可用。支持 MP4/MOV，默认单文件不超过 200MB；管理员和创作者可共同管理，只读成员只能浏览。

- 根目录不计层级，文件夹最多两层；「未分类」用于暂未归档的视频。
- 上传到当前文件夹，批量任务分别显示进度和失败重试；上传开始后目标团队和文件夹固定。
- 多选后使用「移动到」，也可把卡片拖到左侧目录。改名和移动不改变物理文件地址。
- 搜索覆盖整个团队，卡片显示文件所在路径；点击封面播放预览。
- 分镜、故事板参考栏和画布分镜节点可「从资源库选择视频」。画布工具栏也能添加库视频节点，连接到分镜后，通过提示词中的 `@` 显式引用，沿用现有生成流程。
- 库内视频必须符合所选模型的参考视频能力。选择和生成时都会检查，不自动裁剪或转码。
- 参考视频和已生成视频可手动「存入资源库」；入库保存独立文件。新画布视频上传保留后端团队归属记录，仅在手动收藏后显示在库中。

旧画布上传节点只保存浏览器本地信息，没有可供后端验证的团队归属凭据；如需将此类历史视频收藏入库，请先在节点重新上传。现有分镜已持久化的上传参考和已生成的视频可直接收藏。

## 删除行为（已按确认方案实现）

删除不可恢复，视频文件、封面和对应 OSS 对象会被永久删除。允许删除已被使用的资源，旧分镜和画布引用可能失效；已有生成结果保持不变。删除文件夹会递归删除内容。

删除先标记资源不可引用，再清理存储文件，最后移除记录。失败文件保留记录供重试；含失败文件的目录保留。上传或校验中的文件暂不能删除，请等待完成或取消上传。

当前仍沿用已有公共媒体 URL 访问方式，团队隔离覆盖应用列表、管理及资源引用接口，并未将 OSS 桶改为私有。

## 部署与接口

- 新增 `resource_folders`、`video_resources` 两张表，通过现有安全建表流程初始化；不改动原有项目或素材数据。
- 后端配置 `RESOURCE_LIBRARY_MAX_SIZE_MB` 控制文件大小，默认 200；客户端从能力接口读取，不需要新增依赖或改动密钥。
- 复用现有 OSS 提供方，未启用 OSS 时文件保存在媒体目录的 `resource-library/` 子目录。视频探测和封面生成使用已有 ffprobe/ffmpeg。
- 接口前缀 `/api/resource-library`：文件夹 CRUD、资源分页/搜索、重命名、批量移动/删除、删除预览、直传策略及确认、取消上传、内部视频收藏和模型选择校验。
- 引用新增可选 `library_resource_id`，画布提示词引用另使用可选 `mention_name`；无资源 ID 的旧引用继续使用原流程。
- 超管访问资源库必须通过现有团队选择器指定目标团队；关闭鉴权时使用独立默认共享空间。

## 验证

覆盖目录层级、原子移动、角色与团队隔离、真实小视频上传和封面生成、OSS 模拟直传、独立副本、模型校验、删除部分失败、重复删除和重复安全建表。前端覆盖上传目标固定、团队切换隔离、移动和拖拽、选择器、删除失败提示以及画布引用持久化。

未向真实模型发起付费生成，也未对真实 OSS 执行破坏性验收；OSS 流程使用替身测试，本地存储已完成上传、预览和移动的浏览器实测。
