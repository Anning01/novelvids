# 统一团队资源库

[English](resource-library.en.md)

资源库统一管理视频、图片、BGM、音效、静态贴纸、参考音色和角色设定。同一团队内可跨项目复用。原「资产」中的公共角色库、音频库已迁入资源库；「项目资产」保留项目专属角色、场景和道具。

## 使用

- 在侧栏打开「资源库」，按类型、文件夹、来源或名称查找资源。BGM、音效和参考音色使用可试听列表；图片、视频、贴纸和角色使用缩略图。系统内置和团队上传明确区分。
- 上传资源时选择真实用途。BGM／音效支持 MP3、WAV、M4A，静态贴纸支持 PNG、WebP，图片支持 JPG、JPEG、PNG、WebP，视频沿用 MP4、MOV。实际格式和大小由能力接口提供并在服务器校验。
- 原音频库现在称「参考音色」，与 BGM 分开。保留昵称、性别和上传前裁剪，参考片段限制沿用原声音服务。音色可绑定项目旁白、角色主形象或指定形态。
- 「项目资产 → 存入团队资源库」显式发布角色、场景或道具，不会因为历史 `is_global` 默认值自动公开项目内容。角色库的「用于项目」复制设定及形态，保留声音引用；目标项目不可访问的个人音色会阻止应用，要求先核对。默认不覆盖同名的其他角色。
- 媒体的「用于项目」只登记可用来源，不复制文件、不自动生成。两个项目可引用同一 BGM／贴纸，各自拥有独立的裁剪、音量和时间线。
- 剪辑页左侧的媒体、BGM、贴纸均可切换「团队资源库」。BGM 内可筛选配乐和音效。预览不会插入素材，点击 `+` 才添加到对应轨道。管理资源打开新标签页，返回剪辑页时刷新资源列表。
- 项目导入素材可显式存入团队库；重复发布同一项目导入记录复用已完成资源，避免重复复制文件。
- 分镜的资源选择支持模型允许的参考图片／视频；无限画布可读取团队媒体、参考音色、纯数字人和已发布设定。仍使用原节点、端口和模型能力校验，不增加另一套画布逻辑。
- 文件夹最多两层，可混合容纳当前团队不同资源类型。移动和重命名保留稳定引用。个人历史音色保持原来的个人范围，不能直接移入团队目录；系统内置资源只读。
- 删除资源仍需明确确认，可能使历史引用失效。包含角色或参考音色的文件夹须先移出这些记录，不能将删除文件夹变成删除原角色／声音数据的捷径。

## 兼容、权限与回滚

- `VideoResource` 保留历史 `video_resources` 表及数值 ID，新增 `kind`，旧行默认 `video`。旧视频 API 和旧引用结构保留，旧视频接口不会误返回 BGM。
- 统一目录的稳定标识为 `media:<id>`、`voice:<id>`、`human:<id>`、`asset:<id>`，避免不同旧表中的同号 ID 混淆。`resource_placements` 只补充目录信息；`project_resources` 登记项目对媒体的使用。
- 原 `AudioReference`、`DigitalHuman`、`Asset`、`AssetVariant` 的 ID、`asset_id`、提示词和绑定不重建。系统种子仍只在对应表为空时初始化，不覆盖既有记录。
- 资源库所有列表、详情、移动、上传 finalize、应用和实际导出均校验团队或项目。查看者可读取，不可上传、发布、改名、移动、绑定或修改时间线。平台管理员须明确选择团队。
- `/assets` 与 `/videos` 的项目资产入口保留；旧带 `scope=public` 的公共库链接转至资源库对应类型。原音色／数字人 API 保留，旧画布与角色绑定继续可用。
- 兼容更新仅增加字段和新表。部署前备份数据库；回滚代码时可保留新字段／表，不需删表。正式部署仍按仓库规则只保留一份部署前数据库备份和上一版本回滚文件。
- 没有增加生成模型调用或修改计费逻辑。上传、预览和引用使用原媒体存储方式；导出使用本地 FFmpeg。

## 实现位置与验证

- `api/resource_catalog.py`：类型化目录协议和已有权限依赖。
- `services/resource_catalog.py`：合并旧媒体、音色与角色目录，保持范围、稳定身份、过滤与分页一致。
- `services/catalog_applications.py`：通过现有项目写入服务应用媒体、角色和声音绑定。
- `services/catalog_publication.py`：项目素材发布及重复发布复用。
- `services/media_inspection.py`：真实静态图片／音频内容校验。
- `web/src/features/resource-library/`：管理界面、选择器、上传裁剪和剪辑页内团队资源。

已使用隔离 SQLite 数据库和两个项目，通过实际页面上传视频、BGM、贴纸及参考音色，并验证 BGM 跨项目复用、角色形态复用及声音绑定。包含团队 BGM 和贴纸的 1280×720、24fps、6 秒成片已从浏览器导出、下载和完整解码；音轨检测到测试 BGM 的频率成分。没有触发付费生成模型。

PostgreSQL 14.19 隔离实例验证旧视频字段补齐、原 ID／文本保留、重复启动、种子不覆盖和并发项目引用唯一性。深浅主题与窄屏已检查。真实 OSS 账号的网络与访问策略未独立实测；直传、finalize 和幂等契约使用模拟 Provider 回归，并复用现有 OSS 实现。当前贴纸只支持静态图片。

当前工程检查：前端全量 805 项通过，类型检查与生产构建通过；后端全量 1507 项通过，鉴权关闭模式跳过 238 项，权限专项另以鉴权开启模式运行 37 项通过。新目录服务与协议相关代码测得覆盖率 84.84%。`git diff --check` 通过。真实模型测试按仓库既有环境条件处理，本次资源库验收没有发起模型调用。
